# Unity API 字典（UnityAPI Dictionary）

> 这是 Lucy 为「主人」整理的一套 **功能词典式** Unity API 字典。
> 定位：不是教程翻版，而是一本**可以随时查、照着学、入职笔试面试都用得上**的速查工具书。

---

## 一、这套字典怎么用（使用指南）

### 1. 三种查阅入口

| 你的问题 | 去哪里找 |
|---------|---------|
| 「我要做 XX（移动物体/读输入/播放动画）」 | 看各章开头的 **功能速查表**（功能→API） |
| 「某个 API 叫什么、参数怎么传」 | 按 API 名字直接在对应章节查词条 |
| 「这两个 API 长得很像，该用哪个」 | 用 **词条自带的『相似 API 区别』一小节** 或各章末尾的 **对比总表** |

### 2. 词条统一模板（每个 API 都按这个结构讲）

每个词条固定包含以下小节，顺序完全一致，方便你快速定位：

```
【是什么】  这个 API 的本质/类别（属方法、属性、委托、事件、类…）
【用途】    在什么场景下用
【名称含义】 名字拆解（前缀/后缀/单词含义，帮你记）
【参数说明】 每个参数逐一解释（含类型、含义、默认值、可空性）
【返回值】  返回什么，怎么解释这个返回值（尤其是 bool/枚举/引用类型）
【代码示例】 配套的可用代码片段（含注释）
【相似 API 区别】 与功能相近的其他 API 对比表格
【版本标记】 若为较新版本引入的 API，标注「✅ Unity X 引入」
```

> 📍 阅读约定：
> - 标 `[⚠️ 注意]` 的是容易踩坑的地方
> - 有 `[C++/Raylib 类比]` 的是帮你建立已有知识关联的地方
> - 标 `[面试常考]` 的是笔试/面试高频考点

## 三、版本约定（⚠️ 重要）

- 本字典默认基于较通用版本做过一次标注。**「XX 引入 / XX 移除 / XX 弃用」的标注只代表该 API 的生命周期事件，不代表版本号本身准确**——因为 Unity 每个大版本差异很大。
- 标注中出现的版本号（如 `[Unity 2021.3]`）表示：**该 API 或该推荐用法大致在该版本体系下流行/确立**，用于你判断"老的还是新的"。遇到版本差异请以官方文档为准。
- 旧版 `Input` 类与新版 `Input System` 包关系：
  - `Input`（旧，`UnityEngine.Input`）可一直用，但 **不推荐新项目使用**。
  - `Input System`（新包，`UnityEngine.InputSystem`，2019+）是官方推荐替代，主流新项目用它。
