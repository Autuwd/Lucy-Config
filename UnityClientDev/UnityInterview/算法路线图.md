## 一、前缀和

### 📖 教程讲解

**来源文章**：《小而美的算法技巧：前缀和数组》  
🔗 https://labuladong.online/zh/algo/data-structure/prefix-sum/

#### 核心思想

前缀和技巧适用于**快速、频繁地计算一个索引区间内的元素之和**。这个技巧非常简单，但在处理数组区间问题时威力巨大。

**构造思路：**

对于数组 `nums`，我们构造一个 `preSum` 数组，其中 `preSum[i]` 表示 `nums[0..i-1]` 的累加和（下标整体偏移 1，是为了方便处理边界情况）：

```
preSum[0] = 0
preSum[1] = nums[0]
preSum[2] = nums[0] + nums[1]
...
preSum[i] = nums[0] + nums[1] + ... + nums[i-1]
```

**查询思路：**

如果我们想查询 `nums[left..right]` 的区间和：

```
sumRange(left, right) = preSum[right + 1] - preSum[left]
```

这就把原本 O(N) 的查询优化到了 O(1)。代价是用 O(N) 的空间提前做预处理。

#### 二维前缀和

对于二维矩阵，同理可以构造二维前缀和：

`preSum[i][j]` 表示矩阵左上角 `(0,0)` 到 `(i-1,j-1)` 的子矩阵所有元素之和。

查询子矩阵 `(r1,c1)` 到 `(r2,c2)` 的元素和，利用**容斥原理**：

```
sumRegion = preSum[r2+1][c2+1]
           - preSum[r1][c2+1]
           - preSum[r2+1][c1]
           + preSum[r1][c1]
```

即：大矩形 - 左边矩形 - 上面矩形 + 左上角矩形（因为减了两次，要加回一次）。

#### 前缀和 + 哈希表

前缀和与哈希表结合，可以解决「连续子数组和为 K」这类问题。

**关键洞察：** 如果 `preSum[j] - preSum[i] == k`，则 `nums[i..j-1]` 的和为 k。  
换句话说，遍历到位置 `j` 时，只需查找有多少个 `preSum[i] == preSum[j] - k` 即可。

这就是 LeetCode 560 题的核心思路，时间复杂度 O(N)。

---

### 🧩 代码模板（C#）

**一维前缀和**

```csharp
public class NumArray
{
    private int[] preSum;

    public NumArray(int[] nums)
    {
        // preSum[0] = 0，便于统一处理边界
        preSum = new int[nums.Length + 1];
        for (int i = 1; i <= nums.Length; i++)
            preSum[i] = preSum[i - 1] + nums[i - 1];
    }

    // 查询闭区间 [left, right] 的元素和，O(1)
    public int SumRange(int left, int right)
        => preSum[right + 1] - preSum[left];
}
```

**二维前缀和**

```csharp
public class NumMatrix
{
    private int[,] preSum;

    public NumMatrix(int[][] matrix)
    {
        int m = matrix.Length, n = matrix[0].Length;
        preSum = new int[m + 1, n + 1];
        for (int i = 1; i <= m; i++)
            for (int j = 1; j <= n; j++)
                // 容斥原理构造二维前缀和
                preSum[i, j] = preSum[i - 1, j] + preSum[i, j - 1]
                             + matrix[i - 1][j - 1] - preSum[i - 1, j - 1];
    }

    // 查询子矩阵 [r1,c1..r2,c2] 的元素和，O(1)
    public int SumRegion(int r1, int c1, int r2, int c2)
        => preSum[r2 + 1, c2 + 1] - preSum[r1, c2 + 1]
         - preSum[r2 + 1, c1] + preSum[r1, c1];
}
```

#### ⭐ LeetCode 560. 和为 K 的子数组

**题目：** 给你一个整数数组 `nums` 和一个整数 `k`，请你统计并返回该数组中和为 `k` 的**连续子数组的个数**。

**思路详解：**

暴力解法是枚举所有子数组，O(N²)。优化思路如下：

设 `preSum[i]` 为 `nums[0..i-1]` 的前缀和。子数组 `nums[i..j]` 的和为 `preSum[j+1] - preSum[i]`。

我们需要统计满足 `preSum[j] - preSum[i] == k` 的 `(i, j)` 对数。

等价地，对每个 `j`，我们要统计 `preSum[i] == preSum[j] - k` 的 `i` 的数量。

用哈希表记录「每个前缀和值出现的次数」，一次遍历即可完成，O(N) 时间。

**注意：** 初始化时要放入 `map[0] = 1`，代表空子数组（前缀和为 0 本身就存在一次）。

```csharp
public int SubarraySum(int[] nums, int k)
{
    // key: 前缀和的值, value: 该前缀和出现的次数
    var map = new Dictionary<int, int> { [0] = 1 };
    int preSum = 0, count = 0;
    foreach (int num in nums)
    {
        preSum += num;
        // 如果存在 preSum - k 的前缀和，说明中间这段子数组和为 k
        if (map.TryGetValue(preSum - k, out int v))
            count += v;
        map[preSum] = map.GetValueOrDefault(preSum, 0) + 1;
    }
    return count;
}
```

#### LeetCode 238. 除自身以外数组的乘积

**题目：** 给你长度为 `n` 的整数数组 `nums`，返回数组 `answer`，其中 `answer[i]` 等于 `nums` 中除 `nums[i]` 之外其余各元素的乘积。不能使用除法。

**思路：** 前缀积 + 后缀积。先正向遍历建立「左侧前缀积」数组，再逆向遍历时用一个变量追踪「右侧后缀积」，两者相乘即为结果。空间 O(1)（不算结果数组）。

```csharp
public int[] ProductExceptSelf(int[] nums)
{
    int n = nums.Length;
    int[] res = new int[n];
    // 第一步：res[i] 暂时存左侧所有元素的乘积
    res[0] = 1;
    for (int i = 1; i < n; i++)
        res[i] = res[i - 1] * nums[i - 1];
    // 第二步：right 追踪右侧乘积，逆向更新 res[i]
    int right = 1;
    for (int i = n - 1; i >= 0; i--)
    {
        res[i] *= right;   // 左侧积 × 右侧积
        right *= nums[i];  // 更新右侧积
    }
    return res;
}
```

#### LeetCode 525. 连续数组（0 和 1 数量相等的最长子数组）

**题目：** 给定一个二进制数组 `nums`，找到含有相同数量 `0` 和 `1` 的最长连续子数组，并返回该子数组的长度。

**思路：** 经典转化：将 0 视为 -1，则问题变为「和为 0 的最长子数组」。

利用前缀和 + 哈希表：记录每个前缀和**第一次出现**的下标。当同一前缀和再次出现时，说明中间这段子数组和为 0（即 0 和 1 数量相等），用当前下标减去首次出现下标即得长度。

```csharp
public int FindMaxLength(int[] nums)
{
    // key: 前缀和, value: 首次出现的下标
    var map = new Dictionary<int, int> { [0] = -1 };
    int preSum = 0, maxLen = 0;
    for (int i = 0; i < nums.Length; i++)
    {
        preSum += nums[i] == 0 ? -1 : 1; // 0 → -1, 1 → 1
        if (map.TryGetValue(preSum, out int idx))
            maxLen = Math.Max(maxLen, i - idx);
        else
            map[preSum] = i; // 只记录首次出现位置
    }
    return maxLen;
}
```

## 二、差分数组

### 📖 教程讲解

**来源文章**：《小而美的算法技巧：差分数组》  
🔗 https://labuladong.online/zh/algo/data-structure/diff-array/

#### 核心思想

差分数组是前缀和的「逆操作」，适用于频繁对数组某个区间整体进行加减操作的场景。

**差分数组的定义：**

```
diff[0] = nums[0]
diff[i] = nums[i] - nums[i-1]  (i >= 1)
```

**对区间 [i, j] 整体加 val 的操作：**

```
diff[i] += val      // 从 i 开始，后面所有元素都加了 val
diff[j+1] -= val    // 从 j+1 开始，把多加的 val 减回去
```

为什么这样就能实现区间加法？因为差分数组还原为原数组时需要做前缀和：

```
res[0] = diff[0]
res[i] = res[i-1] + diff[i]  (i >= 1)
```

`diff[i] += val` 相当于「从 i 位置开始，让后续所有 `res[i..n-1]` 都加了 val」；  
`diff[j+1] -= val` 则「从 j+1 位置开始，将多加的 val 再减掉」。  
两步结合，最终效果就是 `res[i..j]` 整体加了 val，时间复杂度 O(1)。

**使用场景举例：**

- 航班预订（1109）：对区间航班段预订座位
- 拼车（1094）：对行程区间添加/减少乘客
- 任何「批量区间修改，最后还原结果」的场景

---

### 🧩 代码模板（C#）

```csharp
public class Difference
{
    private int[] diff;

    // 输入一个初始数组，区间操作将在这个数组上进行
    public Difference(int[] nums)
    {
        diff = new int[nums.Length];
        diff[0] = nums[0];
        for (int i = 1; i < nums.Length; i++)
            diff[i] = nums[i] - nums[i - 1];
    }

    // 给闭区间 [i, j] 增加 val（可以是负数）
    public void Increment(int i, int j, int val)
    {
        diff[i] += val;
        // j+1 可能越界（说明 j 是最后一个元素，后面没有需要减去的位置）
        if (j + 1 < diff.Length)
            diff[j + 1] -= val;
    }

    // 返回结果数组：对 diff 做前缀和还原
    public int[] Result()
    {
        int[] res = new int[diff.Length];
        res[0] = diff[0];
        for (int i = 1; i < diff.Length; i++)
            res[i] = res[i - 1] + diff[i];
        return res;
    }
}
```

#### ⭐ LeetCode 1109. 航班预订统计

**题目：** 这里有 `n` 个航班，它们分别从 1 到 n 进行编号。有一份航班预订表 `bookings`，表中第 i 条预订记录 `bookings[i] = [first, last, seats]` 意味着在从 `first` 到 `last` （包含 `first` 和 `last`）的 **每个航班** 上预订了 `seats` 个座位。请你返回一个长度为 `n` 的数组 `answer`，里面的元素是每个航班预订的座位总数。

**思路：** 对航班编号 1~n 建立差分数组。每条预订 `[first, last, seats]` 对应区间 `[first-1, last-1]` 加 `seats`（转成 0 索引）。最后对差分数组做前缀和还原，即为每个航班的总预订量。

```csharp
public int[] CorpFlightBookings(int[][] bookings, int n)
{
    int[] diff = new int[n]; // 差分数组，长度 n
    foreach (var b in bookings)
    {
        int first = b[0] - 1; // 转成 0 索引
        int last  = b[1] - 1;
        int seats = b[2];
        diff[first] += seats;
        if (last + 1 < n)
            diff[last + 1] -= seats;
    }
    // 还原：对差分数组做前缀和
    int[] res = new int[n];
    res[0] = diff[0];
    for (int i = 1; i < n; i++)
        res[i] = res[i - 1] + diff[i];
    return res;
}
```

#### ⭐ LeetCode 1094. 拼车

**题目：** 假设你是一位顺风车司机，汽车最多可以搭载 `capacity` 位乘客。给你一个数组 `trips`，`trips[i] = [num, from, to]` 表示第 `i` 次行程有 `num` 名乘客，他们从站点 `from` 上车，到站点 `to` 下车（**不在 `to` 站占用座位**）。如果你能完成所有的行程，返回 `true`，否则返回 `false`。

**思路：** 对站点序号建立差分数组：在 `from` 站上车（+num），在 `to` 站下车（-num，注意 `to` 站乘客已下车，不占位）。还原后检查每站的人数是否超过 `capacity`。

```csharp
public bool CarPooling(int[][] trips, int capacity)
{
    // 题目保证 0 <= from < to <= 1000，所以差分数组开 1001 足够
    int[] diff = new int[1001];
    foreach (var t in trips)
    {
        int num  = t[0];
        int from = t[1]; // 在 from 站上车
        int to   = t[2]; // 在 to 站下车（to 站起不占位）
        diff[from] += num;
        diff[to]   -= num; // to 站下车，所以 to 处减去
    }
    // 还原并检查是否超载
    int cur = 0;
    foreach (int d in diff)
    {
        cur += d;
        if (cur > capacity) return false;
    }
    return true;
}
```

## 三、二维数组花式遍历

### 📖 教程讲解

**来源文章**：《二维数组的花式遍历技巧》  
🔗 https://labuladong.online/zh/algo/practice-in-action/2d-array-traversal-summary/

#### 矩阵旋转的技巧

旋转矩阵的关键是找到坐标变换规律，从而**不借助辅助数组原地完成旋转**。

**顺时针旋转 90°：**

直接找规律：`matrix[row][col]` → `matrix[col][n-1-row]`，但原地交换涉及 4 个位置，不好处理。

更优雅的方法：**先沿主对角线翻转，再整体水平翻转**，两步操作等价于顺时针旋转 90°。

```
原矩阵:          沿对角线翻转:      水平翻转（逆时针→顺时针）:
1 2 3            1 4 7             7 4 1
4 5 6    →       2 5 8     →       8 5 2
7 8 9            3 6 9             9 6 3
```

**逆时针旋转 90°：** 先沿主对角线翻转，再垂直翻转（上下翻转）。

#### 螺旋遍历矩阵

螺旋遍历的关键是维护四个边界变量 `top, bottom, left, right`，每遍历完一条边就收缩对应的边界，直到遍历完所有元素。

---

### 🧩 代码模板（C#）

```csharp
// 顺时针旋转矩阵 90°（原地）
public void Rotate(int[][] matrix)
{
    int n = matrix.Length;
    // 第一步：沿主对角线翻转（matrix[i][j] ↔ matrix[j][i]）
    for (int i = 0; i < n; i++)
        for (int j = i + 1; j < n; j++)
            (matrix[i][j], matrix[j][i]) = (matrix[j][i], matrix[i][j]);
    // 第二步：每行水平翻转（左右对称）
    for (int i = 0; i < n; i++)
        for (int j = 0, k = n - 1; j < k; j++, k--)
            (matrix[i][j], matrix[i][k]) = (matrix[i][k], matrix[i][j]);
}

// 螺旋遍历矩阵
public IList<int> SpiralOrder(int[][] matrix)
{
    int m = matrix.Length, n = matrix[0].Length;
    int top = 0, bottom = m - 1, left = 0, right = n - 1;
    var res = new List<int>();
    while (res.Count < m * n)
    {
        // 上边：从左到右
        if (top <= bottom)
            for (int j = left; j <= right; j++) res.Add(matrix[top][j]);
        top++;
        // 右边：从上到下
        if (left <= right)
            for (int i = top; i <= bottom; i++) res.Add(matrix[i][right]);
        right--;
        // 下边：从右到左
        if (top <= bottom)
            for (int j = right; j >= left; j--) res.Add(matrix[bottom][j]);
        bottom--;
        // 左边：从下到上
        if (left <= right)
            for (int i = bottom; i >= top; i--) res.Add(matrix[i][left]);
        left++;
    }
    return res;
}
```

```csharp
public int[][] GenerateMatrix(int n)
{
    var matrix = new int[n][];
    for (int i = 0; i < n; i++) matrix[i] = new int[n];
    int top = 0, bottom = n - 1, left = 0, right = n - 1, num = 1;
    while (num <= n * n)
    {
        if (top <= bottom)
            for (int j = left; j <= right; j++) matrix[top][j] = num++;
        top++;
        if (left <= right)
            for (int i = top; i <= bottom; i++) matrix[i][right] = num++;
        right--;
        if (top <= bottom)
            for (int j = right; j >= left; j--) matrix[bottom][j] = num++;
        bottom--;
        if (left <= right)
            for (int i = bottom; i >= top; i--) matrix[i][left] = num++;
        left++;
    }
    return matrix;
}
```

## 四、数组双指针

### 📖 教程讲解

**来源文章**：《双指针技巧秒杀七道数组题目》  
🔗 https://labuladong.online/zh/algo/essential-technique/array-two-pointers-summary/

#### 快慢指针（同向双指针）

快慢指针是原地修改数组的利器。`slow` 指针维护「已处理好」的区间，`fast` 指针负责探路。

**原地去重的逻辑：**

`fast` 每次向右走一步；当 `nums[fast] != nums[slow]` 时，说明发现了新元素，则先让 `slow` 前进一步，再将 `nums[fast]` 赋值过来。

这样 `nums[0..slow]` 始终是去重后的结果。

**应用推广：**

- 移除指定元素（27）：`fast` 遇到不等于 `val` 的才赋给 `slow`
- 移动零（283）：`fast` 遇到非零才赋给 `slow`，最后补零

#### 左右指针（相向双指针）

两个指针从两端向中间逼近，适合有序数组或需要枚举两端元素的场景。

**两数之和的逻辑：**

有序数组中，`left` 从最左、`right` 从最右出发。`sum < target` 则 `left++`（需要更大的值），`sum > target` 则 `right--`（需要更小的值），直到找到目标。

**回文串判断：**

从中心向两端扩展（注意奇偶两种情况），如果两端字符始终相等，则是回文串。

---

### 🧩 代码模板（C#）

```csharp
// 快慢指针——有序数组原地去重，返回新长度
public int RemoveDuplicates(int[] nums)
{
    if (nums.Length == 0) return 0;
    int slow = 0, fast = 0;
    while (fast < nums.Length)
    {
        if (nums[fast] != nums[slow])
        {
            slow++;
            nums[slow] = nums[fast]; // 维护 nums[0..slow] 无重复
        }
        fast++;
    }
    return slow + 1; // 长度 = 最后一个有效下标 + 1
}

// 左右指针——有序数组两数之和
public int[] TwoSum(int[] numbers, int target)
{
    int left = 0, right = numbers.Length - 1;
    while (left < right)
    {
        int sum = numbers[left] + numbers[right];
        if      (sum == target) return new int[] { left + 1, right + 1 };
        else if (sum < target)  left++;
        else                    right--;
    }
    return new int[] { -1, -1 };
}
```

#### ⭐ LeetCode 11. 盛最多水的容器

**题目：** 给定一个长度为 `n` 的整数数组 `height`。有 `n` 条竖线，第 `i` 条线的两个端点是 `(i, 0)` 和 `(i, height[i])`。找出其中的两条线，使得它们与 x 轴共同构成的容器可以容纳最多的水。返回容器可以储存的最大水量。

**思路：** 左右指针，`left` 从最左、`right` 从最右。

- 容量 = `min(height[left], height[right]) * (right - left)`
- 每次移动**较矮的一侧**：移动较高的一侧不可能让容量增大（宽度减小了，高度又受较矮一侧限制没变），移动较矮的一侧才有增大的可能。

```csharp
public int MaxArea(int[] height)
{
    int left = 0, right = height.Length - 1, res = 0;
    while (left < right)
    {
        int area = Math.Min(height[left], height[right]) * (right - left);
        res = Math.Max(res, area);
        // 移动较矮的那一侧
        if (height[left] < height[right]) left++;
        else right--;
    }
    return res;
}
```

#### ⭐ LeetCode 5. 最长回文子串

**题目：** 给你一个字符串 `s`，找到 `s` 中最长的回文子串。

**思路：** 以每个字符为中心向两端扩展（中心扩散法）。注意回文串有奇偶两种：
- 奇数长度：以 `s[i]` 为中心
- 偶数长度：以 `s[i]` 和 `s[i+1]` 之间为中心

对每个位置枚举这两种情况，取最长的结果。

```csharp
public string LongestPalindrome(string s)
{
    string res = "";
    for (int i = 0; i < s.Length; i++)
    {
        string odd  = Expand(s, i, i);     // 奇数长度回文
        string even = Expand(s, i, i + 1); // 偶数长度回文
        if (odd.Length  > res.Length) res = odd;
        if (even.Length > res.Length) res = even;
    }
    return res;
}

// 从 l, r 向外扩展，返回最长回文子串
private string Expand(string s, int l, int r)
{
    while (l >= 0 && r < s.Length && s[l] == s[r])
    { l--; r++; }
    // 循环结束时 l, r 已越界，回文范围是 [l+1, r-1]
    return s.Substring(l + 1, r - l - 1);
}
```

## 五、滑动窗口

### 📖 教程讲解

**来源文章**：《滑动窗口算法核心代码模板》  
🔗 https://labuladong.online/zh/algo/essential-technique/sliding-window-framework/

#### 核心思想

滑动窗口是快慢双指针的进阶形式，`left` 和 `right` 两个指针维护一个动态的窗口 `[left, right)`，整个算法的时间复杂度是 **O(N)**，因为每个元素最多进入窗口一次、离开窗口一次。

**框架三问（解题时逐一回答）：**

1. **什么时候扩大窗口（`right` 右移）？** 通常是一直右移，进入窗口时更新窗口数据。
2. **什么时候缩小窗口（`left` 右移）？** 当窗口内数据不满足或超过某条件时。
3. **什么时候更新答案？**
   - 寻找**最小**子串：在缩小窗口时（窗口刚好满足条件）更新答案。
   - 寻找**最大**子串：在扩大窗口时（窗口每次满足条件）更新答案。

#### 典型问题分析

**最小覆盖子串（76）：** 窗口内必须包含 `t` 的所有字符（且各自数量满足）。`valid` 变量追踪已满足的字符种数，当 `valid == need.Count` 时收缩窗口，同时记录最小长度。

**字符串排列（567）：** 窗口大小固定为 `s1.Length`，判断窗口内是否是 `s1` 的异位词，等价于 `valid == need.Count`。

**无重复最长子串（3）：** 当 `window[c] > 1` 时说明有重复，收缩窗口直到消除重复。每次收缩后更新最大长度。

---

### 🧩 代码模板（C#）

```csharp
// 通用滑动窗口框架（以字符匹配类问题为例）
void SlidingWindow(string s, string t)
{
    var need   = new Dictionary<char, int>(); // t 中每个字符的需求量
    var window = new Dictionary<char, int>(); // 窗口中已有的字符数量
    foreach (char c in t)
        need[c] = need.GetValueOrDefault(c, 0) + 1;

    int left = 0, right = 0;
    int valid = 0; // 已满足需求的字符种数

    while (right < s.Length)
    {
        char c = s[right++]; // c 进入窗口
        if (need.ContainsKey(c))
        {
            window[c] = window.GetValueOrDefault(c, 0) + 1;
            if (window[c] == need[c]) valid++; // 该字符需求恰好满足
        }

        while (/* 收缩条件 */ valid == need.Count)
        {
            // *** 在此更新最小结果 ***

            char d = s[left++]; // d 离开窗口
            if (need.ContainsKey(d))
            {
                if (window[d] == need[d]) valid--; // 该字符需求不再满足
                window[d]--;
            }
        }
    }
    // *** 在此更新最大结果（若是求最大的情况） ***
}
```

#### ⭐ LeetCode 76. 最小覆盖子串（Hard）

**题目：** 给你一个字符串 `s`、一个字符串 `t`。返回 `s` 中涵盖 `t` 所有字符的最小子串。如果 `s` 中不存在涵盖 `t` 所有字符的子串，则返回空字符串 `""`。

**思路：** 标准滑动窗口。当 `valid == need.Count` 时（窗口满足条件），更新最小长度并收缩窗口。

```csharp
public string MinWindow(string s, string t)
{
    var need   = new Dictionary<char, int>();
    var window = new Dictionary<char, int>();
    foreach (char c in t) need[c] = need.GetValueOrDefault(c, 0) + 1;

    int left = 0, right = 0, valid = 0;
    int start = 0, minLen = int.MaxValue;

    while (right < s.Length)
    {
        char c = s[right++];
        if (need.ContainsKey(c))
        {
            window[c] = window.GetValueOrDefault(c, 0) + 1;
            if (window[c] == need[c]) valid++;
        }
        // 当所有字符需求都满足时，尝试缩小窗口
        while (valid == need.Count)
        {
            if (right - left < minLen)
            {
                start  = left;
                minLen = right - left;
            }
            char d = s[left++];
            if (need.ContainsKey(d))
            {
                if (window[d] == need[d]) valid--;
                window[d]--;
            }
        }
    }
    return minLen == int.MaxValue ? "" : s.Substring(start, minLen);
}
```

#### ⭐ LeetCode 567. 字符串的排列

**题目：** 给你两个字符串 `s1` 和 `s2`，写一个函数来判断 `s2` 是否包含 `s1` 的排列。如果是，返回 `true`；否则，返回 `false`。

**思路：** 定长滑动窗口（窗口大小固定为 `s1.Length`），判断 `valid == need.Count`。当窗口大小达到 `s1.Length` 时就要开始收缩。

```csharp
public bool CheckInclusion(string s1, string s2)
{

    foreach (char c in s1) need[c] = need.GetValueOrDefault(c, 0) + 1;

    int left = 0, right = 0, valid = 0;
    while (right < s2.Length)
    {
        char c = s2[right++];
        if (need.ContainsKey(c))
        {
            window[c] = window.GetValueOrDefault(c, 0) + 1;
            if (window[c] == need[c]) valid++;

        // 窗口大小等于 s1 长度时判断并收缩

            if (need.ContainsKey(d))

            }
```

#### ⭐ LeetCode 3. 无重复字符的最长子串

**题目：** 给定一个字符串 `s`，请你找出其中不含有重复字符的**最长子串**的长度。

**思路：** 当 `window[c] > 1` 时说明窗口中出现了重复字符，收缩左边界直到重复消失。每次更新最大长度，注意是在收缩之后（此时窗口满足无重复条件）。

```csharp
public int LengthOfLongestSubstring(string s)
{
    var window = new Dictionary<char, int>();
    int left = 0, right = 0, res = 0;
    while (right < s.Length)
    {
        char c = s[right++];
        window[c] = window.GetValueOrDefault(c, 0) + 1;
        // 出现重复时收缩左边
        while (window[c] > 1)
        {
            char d = s[left++];
            window[d]--;
        }
        res = Math.Max(res, right - left); // 此时窗口内无重复
    }
    return res;
}
```

## 六、二分搜索

### 📖 教程讲解

**来源文章**：《我写了首诗，把二分搜索算法变成了默写题》  
🔗 https://labuladong.online/zh/algo/essential-technique/binary-search-framework/

#### 为什么二分搜索难写对？

Knuth 大佬说：「思路很简单，细节是魔鬼。」二分查找真正的坑在于：

- `while` 里到底用 `<=` 还是 `<`？
- `left = mid + 1` 还是 `left = mid`？  
- `right = mid - 1` 还是 `right = mid`？

根本原因是**没有搞清楚「搜索区间」的概念**。

#### 搜索区间的核心概念

**「搜索区间」**是 `left` 和 `right` 所代表的含义，决定了 while 条件和边界更新方式。

本文统一使用**「两端都闭」的写法** `[left, right]`（即 `right = nums.Length - 1`），原则是：

> 二分搜索的本质，就是利用 `while` 循环调整 `left` 和 `right` 指针，不断收缩搜索区间，最终锁定目标值所在的那个索引。

**为什么用 `<=`？**

`while (left <= right)` 的终止条件是 `left == right + 1`，即搜索区间 `[right+1, right]` 为空，正确终止。若用 `<`，终止时区间 `[left, left]` 还有一个元素，可能漏掉。

**为什么 `left = mid + 1`，`right = mid - 1`？**

因为 `mid` 已经检查过了，下一步应从搜索区间中排除它：
- 如果 target 更大，新区间是 `[mid+1, right]`，故 `left = mid + 1`
- 如果 target 更小，新区间是 `[left, mid-1]`，故 `right = mid - 1`

#### 三种场景的统一写法

三种场景（精确查找、找左边界、找右边界）的唯一区别在于 `nums[mid] == target` 时怎么处理：

| 场景 | `nums[mid] == target` 时 | 返回值 |
|------|--------------------------|--------|
| 精确查找 | `return mid`（直接返回） | mid |
| 找左边界 | `right = mid - 1`（收缩右边，继续往左找） | left |
| 找右边界 | `left = mid + 1`（收缩左边，继续往右找） | right |

**二分思维的精髓：** 通过已知信息尽可能多地收缩（折半）搜索空间，从而增加穷举效率，快速找到目标。

#### 二分搜索的高级应用：搜索答案空间

二分不只能搜索有序数组，还能用于「最小化最大值」「最大化最小值」之类的问题。思路是：

1. 分析答案的值域范围（min ~ max）
2. 在值域上做二分，验证「当答案为 mid 时是否可行」
3. 根据可行性调整左右边界，找到临界值

---

### 🧩 代码模板（C#）

```csharp
// 精确查找
int BinarySearch(int[] nums, int target)
{
    int left = 0, right = nums.Length - 1;
    while (left <= right)
    {
        int mid = left + (right - left) / 2; // 防止溢出
        if      (nums[mid] == target) return mid;
        else if (nums[mid] <  target) left  = mid + 1;
        else                          right = mid - 1;
    }
    return -1;
}

// 搜索左边界（target 存在时返回最左下标；不存在返回 -1）
int LeftBound(int[] nums, int target)
{
    int left = 0, right = nums.Length - 1;
    while (left <= right)
    {
        int mid = left + (right - left) / 2;
        if      (nums[mid] == target) right = mid - 1; // 别返回，继续向左收缩
        else if (nums[mid] <  target) left  = mid + 1;
        else                          right = mid - 1;
    }
    // 检查 left 越界或不等于 target
    if (left >= nums.Length || nums[left] != target) return -1;
    return left;
}

// 搜索右边界（target 存在时返回最右下标；不存在返回 -1）
int RightBound(int[] nums, int target)
{
    int left = 0, right = nums.Length - 1;
    while (left <= right)
    {
        int mid = left + (right - left) / 2;
        if      (nums[mid] == target) left  = mid + 1; // 别返回，继续向右收缩
        else if (nums[mid] <  target) left  = mid + 1;
        else                          right = mid - 1;
    }
    // 检查 right 越界或不等于 target
    if (right < 0 || nums[right] != target) return -1;
    return right;
}
```

#### ⭐ LeetCode 875. 爱吃香蕉的珂珂

**题目：** 珂珂喜欢吃香蕉。这里有 `n` 堆香蕉，第 `i` 堆中有 `piles[i]` 根香蕉。警卫已经离开了，将在 `h` 小时后回来。珂珂可以决定她吃香蕉的速度 `k`（单位：根/小时）。每个小时她将会选择一堆香蕉，从中吃掉 `k` 根。如果这堆香蕉少于 `k` 根，她将吃掉这堆的所有香蕉，然后这一小时内不会再吃更多的香蕉。求她可以在 `h` 小时内吃掉所有香蕉的**最小速度** `k`。

**思路：** 在值域 `[1, max(piles)]` 上做二分，寻找「最小满足条件的速度」（即左边界）。验证函数：以速度 `speed` 能否在 `h` 小时内吃完（每堆需要 `⌈piles[i]/speed⌉` 小时）。

```csharp
public int MinEatingSpeed(int[] piles, int h)
{
    int left = 1, right = piles.Max();
    // 搜索左边界：最小的满足条件的速度
    while (left < right)
    {
        int mid = left + (right - left) / 2;
        if (CanFinish(piles, mid, h))
            right = mid;      // mid 可行，尝试更慢
        else
            left = mid + 1;   // mid 不可行，必须更快
    }
    return left;
}

bool CanFinish(int[] piles, int speed, int h)
{
    int totalHours = 0;
    foreach (int p in piles)
        totalHours += (p + speed - 1) / speed; // ⌈p/speed⌉ 向上取整
    return totalHours <= h;
}
```

#### ⭐ LeetCode 1011. 在 D 天内送达包裹的能力

**题目：** 传送带上的包裹必须在 `days` 天内从一个港口运送到另一个港口。传送带上的第 `i` 个包裹的重量为 `weights[i]`。每天都会按给出重量的顺序往传送带上装载包裹（必须按顺序装，不能跳过），我们装载的重量不会超过船的最大运载重量。返回能在 `days` 天内将传送带上所有包裹送达的船的**最低运载能力**。

**思路：** 在值域 `[max(weights), sum(weights)]` 上做二分找左边界。验证函数：以运力 `cap` 能否在 `days` 天内运完（贪心模拟逐天装载）。

```csharp
public int ShipWithinDays(int[] weights, int days)
{
    int left = weights.Max(), right = weights.Sum();
    while (left < right)
    {
        int mid = left + (right - left) / 2;
        if (CanShip(weights, mid, days))
            right = mid;
        else
            left = mid + 1;
    }
    return left;
}

bool CanShip(int[] weights, int cap, int days)
{
    int d = 1, cur = 0;
    foreach (int w in weights)
    {
        if (cur + w > cap) { d++; cur = 0; } // 当天装不下，换下一天
        cur += w;
    }
    return d <= days;
}
```

## 七、链表双指针

### 📖 教程讲解

**来源文章**：《双指针技巧秒杀七道链表题目》  
🔗 https://labuladong.online/zh/algo/essential-technique/linked-list-skills-summary/

#### 快慢指针的应用

链表没有下标，不能随机访问，但快慢指针（一个走一步、一个走两步）可以解决很多链表问题：

**1. 找链表中点：**

快指针走两步，慢指针走一步，快指针到达末尾时，慢指针恰好在中点。（若长度为偶数，`slow` 停在后半段的第一个节点）

**2. 找倒数第 k 个节点：**

快指针先走 k 步，然后快慢指针同速前进，快指针到达末尾时，慢指针恰好在倒数第 k 个。

**3. 检测环：**

快慢指针同时从 head 出发，若有环则必然相遇（如同跑道追及问题）。

**4. 找环的入口：**

快慢指针相遇后，将其中一个移回 head，两者同速前进，再次相遇处即为环的入口。

**数学原理：** 设环外距离为 `a`，环长为 `b`。快慢相遇时慢指针走了 `a + m*b + r`，快指针走了 `2(a + m*b + r)`。相遇点距环入口距离为 `r`，而环长 - r = a mod b，所以再走 a 步（即从 head 出发）恰好能到入口。

**5. 两链表相交：**

两个指针分别遍历两个链表，到达末尾后互换起点，由于路径总长相同，它们会在交叉点相遇（若无交叉则同时到 null）。

### 🧩 代码模板（C#）

```csharp
public class ListNode { public int val; public ListNode next; }

// 找链表中点
ListNode FindMiddle(ListNode head)
{
    var slow = head; var fast = head;
    while (fast != null && fast.next != null)
    {
        slow = slow.next;
        fast = fast.next.next;
    }
    return slow;
}

// 找倒数第 k 个节点（假设 k 合法）
ListNode FindKthFromEnd(ListNode head, int k)
{
    var fast = head;
    for (int i = 0; i < k; i++) fast = fast.next; // 快指针先走 k 步
    var slow = head;
    while (fast != null) { slow = slow.next; fast = fast.next; }
    return slow;
}

// 检测环
bool HasCycle(ListNode head)
{
    var slow = head; var fast = head;
    while (fast != null && fast.next != null)
    {
        slow = slow.next; fast = fast.next.next;
        if (slow == fast) return true;
    }
    return false;
}

// 找环的入口
ListNode DetectCycle(ListNode head)
{
    var slow = head; var fast = head;
    while (fast != null && fast.next != null)
    {
        slow = slow.next; fast = fast.next.next;
        if (slow == fast)
        {
            slow = head; // 一个回到起点
            while (slow != fast) { slow = slow.next; fast = fast.next; }
            return slow; // 再次相遇即为入口
        }
    }
    return null;
}
```

**题目：** 将两个升序链表合并为一个新的**升序**链表并返回。新链表是通过拼接给定的两个链表的所有节点组成的。

```csharp
public ListNode MergeTwoLists(ListNode l1, ListNode l2)
{

    var cur = dummy;
    while (l1 != null && l2 != null)
    {
        if (l1.val <= l2.val) { cur.next = l1; l1 = l1.next; }
        else                  { cur.next = l2; l2 = l2.next; }
        cur = cur.next;
    }
    cur.next = l1 ?? l2; // 接上剩余部分
    return dummy.next;
}
```

**题目：** 给你两个单链表的头节点 `headA` 和 `headB`，请你找出并返回两个单链表相交的起始节点。如果两个链表不存在相交节点，返回 `null`。

```csharp
public ListNode GetIntersectionNode(ListNode headA, ListNode headB)
{
    var p1 = headA; var p2 = headB;
    while (p1 != p2)
    {
        p1 = p1 == null ? headB : p1.next;
        p2 = p2 == null ? headA : p2.next;
    }
    return p1; // 相交则为交点，不相交则为 null
}
```

## 八、递归操作链表

### 📖 教程讲解

**来源文章**：《递归魔法：反转单链表》  
🔗 https://labuladong.online/zh/algo/data-structure/reverse-linked-list/

#### 递归反转链表的关键

递归函数的**函数定义（语义）** 是理解递归的核心。

以 `ReverseList(head)` 为例，函数定义：「输入链表头节点，将整个链表反转，返回新的头节点」。

反转 `head.next` 之后的链表（递归已经帮我们做完了），现在只差 `head` 这个节点没有接到末尾：

```
反转前：  head → [已反转的链表] → null
反转后：  [已反转的链表] → head → null
             ↑
             last（新头节点）
```

所以只需：`head.next.next = head; head.next = null;`

**难点：** 要在「相信递归函数会正确完成其定义工作」的基础上写代码，不要试图在脑子里展开递归过程。

### 📝 习题详解

#### LeetCode 206. 反转链表

**题目：** 给你单链表的头节点 `head`，请你反转链表，并返回反转后的链表。

```csharp
public ListNode ReverseList(ListNode head)
{
    // base case：空链表或只有一个节点
    if (head == null || head.next == null) return head;
    // 递归：先反转 head.next 之后的部分
    ListNode last = ReverseList(head.next);
    // 将 head 接到已反转部分的末尾
    head.next.next = head;
    head.next = null;
    return last; // 返回新头节点
}
```

#### ⭐ LeetCode 92. 反转链表 II

**题目：** 给你单链表的头节点 `head` 和两个整数 `left` 和 `right`，其中 `left <= right`。请你反转从位置 `left` 到位置 `right` 的链表节点，返回**反转后的链表**。

**思路：** 先找到 `left` 位置的前驱节点，然后在其后反转 `right - left + 1` 个节点，最后重新接好。用迭代方式更直观。

```csharp
public ListNode ReverseBetween(ListNode head, int left, int right)
{
    var dummy = new ListNode { next = head };
    var pre = dummy;
    // 找到第 left 个节点的前驱
    for (int i = 1; i < left; i++) pre = pre.next;

    // 反转 [left, right] 这段链表
    ListNode prev = null, cur = pre.next;
    for (int i = 0; i < right - left + 1; i++)
    {
        var next = cur.next;
        cur.next = prev;
        prev = cur;
        cur = next;
    }
    // 重新接好：pre → [反转后的尾] → [原来 right 之后的部分]
    pre.next.next = cur;  // pre.next 现在是原来第 left 个（已成为尾部）
    pre.next = prev;      // prev 是反转后的头部
    return dummy.next;
}
```

#### ⭐ LeetCode 25. K 个一组翻转链表（Hard）

**题目：** 给你链表的头节点 `head`，每 `k` 个节点一组进行翻转，请你返回修改后的链表。如果节点总数不是 `k` 的整数倍，请将最后剩余的节点保持原有顺序。

**思路：** 递归。每次取前 k 个节点做反转，然后递归处理剩余部分，再把两段链接起来。

```csharp
public ListNode ReverseKGroup(ListNode head, int k)
{
    // 检查是否有 k 个节点
    var b = head;
    for (int i = 0; i < k; i++)
    {
        if (b == null) return head; // 不足 k 个，不反转
        b = b.next;
    }
    // 反转 [head, b) 这 k 个节点
    ListNode prev = null, cur = head;
    while (cur != b)
    {
        var next = cur.next;
        cur.next = prev;
        prev = cur;
        cur = next;
    }
    // head 是原来第一个节点，反转后变成尾部，接上递归结果
    head.next = ReverseKGroup(b, k);
    return prev; // prev 是反转后的新头节点
}
```

## 九、二叉树核心思维

### 📖 教程讲解

**来源文章**：《二叉树系列算法核心纲领》  
🔗 https://labuladong.online/zh/algo/essential-technique/binary-tree-summary/

#### 两种解题思维模式

二叉树解题的思维模式分两类：

**1. 遍历思路：** 能否通过遍历一遍二叉树得到答案？如果可以，用一个 `Traverse` 函数配合**外部变量**来实现。

**2. 分解问题思路：** 能否定义一个递归函数，通过**子问题（子树）的答案**推导出原问题的答案？如果可以，写出这个递归函数的定义，充分利用其**返回值**。

无论哪种思路，都要思考：**单独抽出一个节点，它需要做什么？需要在哪个时机（前/中/后序）做？**

#### 前中后序位置的本质

```
void Traverse(TreeNode root) {
    // 前序位置：刚进入节点时执行
    Traverse(root.left);
    // 中序位置：左子树遍历完，即将遍历右子树时执行
    Traverse(root.right);
    // 后序位置：即将离开节点时执行（能同时看到左右子树的结果）
}
```

**三个位置的能力依次递增：**

- **前序**：只能从父节点（参数）获取信息，适合「自顶向下传递信息」
- **中序**：主要用于 BST（中序遍历 BST = 有序序列）
- **后序**：可以同时获取左右子树的返回值，能力最强。**凡是和子树有关的问题，大概率在后序位置做文章。**

#### 快速排序 vs 归并排序的二叉树视角

这个视角非常重要，能帮你深刻理解二叉树思维：

- **快速排序 = 二叉树前序遍历**：先选 pivot 分区（前序位置做事），再递归左右子数组
- **归并排序 = 二叉树后序遍历**：先递归左右子数组排好序，再合并（后序位置做事）

如果能一眼看出这个联系，就说明已经掌握了二叉树的精髓。

#### 动态规划 / 回溯 / DFS 的本质区别

> 动归/DFS/回溯算法都可以看做二叉树问题的扩展，只是关注点不同：
>
> - **动态规划**：属于「分解问题」思路，关注整棵**子树**
> - **回溯算法**：属于「遍历」思路，关注节点间的**树枝**（选择/撤销）
> - **DFS**：属于「遍历」思路，关注单个**节点**

这决定了「做选择」和「撤销选择」代码的位置：

- DFS：`做选择` → `for(递归子节点)` → `撤销选择`（在 for 循环**外面**）
- 回溯：`for(做选择 → 递归 → 撤销选择)`（在 for 循环**里面**，针对每条树枝）

---

### 🧩 代码模板（C#）

```csharp
public class TreeNode { public int val; public TreeNode left, right; }

// 遍历框架
void Traverse(TreeNode root)
{
    if (root == null) return;
    // 前序位置
    Traverse(root.left);
    // 中序位置
    Traverse(root.right);
    // 后序位置
}

// 层序遍历（BFS）
IList<IList<int>> LevelOrder(TreeNode root)
{
    var res = new List<IList<int>>();
    if (root == null) return res;
    var queue = new Queue<TreeNode>();
    queue.Enqueue(root);
    while (queue.Count > 0)
    {
        int sz = queue.Count;
        var level = new List<int>();
        for (int i = 0; i < sz; i++)
        {
            var node = queue.Dequeue();
            level.Add(node.val);
            if (node.left  != null) queue.Enqueue(node.left);
            if (node.right != null) queue.Enqueue(node.right);
        }
        res.Add(level);
    }
    return res;
}
```

#### ⭐ LeetCode 104. 二叉树的最大深度

**题目：** 给定一个二叉树 `root`，返回其最大深度（根节点到最远叶子节点的最长路径上的节点数）。

**思路 A（分解问题）：** 最大深度 = 1 + max(左子树最大深度, 右子树最大深度)，后序位置推导。

```csharp
public int MaxDepth(TreeNode root)
{
    if (root == null) return 0;
    int leftMax  = MaxDepth(root.left);
    int rightMax = MaxDepth(root.right);
    return 1 + Math.Max(leftMax, rightMax); // 后序位置
}
```

#### ⭐ LeetCode 543. 二叉树的直径

**题目：** 给你一棵二叉树的根节点，返回该树的**直径**（任意两个节点之间最长路径的**边数**，路径不一定经过根节点）。

**思路：** 每条直径 = 某节点的左子树深度 + 右子树深度。用后序位置同时计算当前节点的深度并更新全局最大直径。

#### ⭐ LeetCode 124. 二叉树中的最大路径和（Hard）

**题目：** 二叉树中的**路径**被定义为一条从树中任意节点出发，沿父节点-子节点连接，达到任意节点的序列。同一个节点在一条路径序列中**至多出现一次**。该路径**至少包含一个**节点，且不一定经过根节点。给你二叉树的根节点 `root`，返回其**最大路径和**。

**思路：** 后序位置。对每个节点，经过该节点的最大路径和 = `root.val + max(0, 左贡献) + max(0, 右贡献)`（负数贡献就不选）。向父节点返回的值是 `root.val + max(0, 左贡献, 右贡献)`（只能选一侧延伸，不能同时向左右延伸）。

```csharp
int maxSum = int.MinValue;
public int MaxPathSum(TreeNode root)
{
    DfsPath(root);
    return maxSum;
}
int DfsPath(TreeNode root)
{
    if (root == null) return 0;
    // 负收益直接取 0（不选该方向）
    int left  = Math.Max(0, DfsPath(root.left));
    int right = Math.Max(0, DfsPath(root.right));
    // 后序位置：以 root 为拐点的最大路径和
    maxSum = Math.Max(maxSum, root.val + left + right);
    // 向父节点返回：只能选一侧继续延伸
    return root.val + Math.Max(left, right);
}
```

## 十、BFS 广度优先搜索

### 📖 教程讲解

**来源文章**：《BFS 算法解题套路框架》  
🔗 https://labuladong.online/zh/algo/essential-technique/bfs-framework/

#### BFS 的本质

BFS（广度优先搜索）的本质是在一幅「图」中找到从起点 `start` 到终点 `target` 的**最短距离**。

BFS 和 DFS 的核心区别：

| | BFS | DFS |
|--|-----|-----|
| 数据结构 | 队列 | 栈（或递归调用栈） |
| 探索方式 | 按距离由近及远扩展 | 一条路走到黑 |
| 最短路径 | ✅ 有保证（无权图） | ❌ 无保证 |
| 空间开销 | 较大（需存储一层的所有节点） | 较小（只存当前路径） |

**BFS 为什么能找最短路径？** 因为 BFS 是按「步数」一层一层向外扩展的，第一次到达目标节点时，走过的步数就是最少步数。

#### 双向 BFS 优化

普通 BFS 是从一个方向扩展，双向 BFS 从起点和终点**同时扩展**，当两个扩展集合相交时停止，搜索空间可以大幅缩小（O(k^{d/2}) vs O(k^d)）。

但双向 BFS 需要知道终点，适用于终点固定的问题。

---

### 🧩 代码模板（C#）

```csharp
// BFS 最短路径框架
int Bfs(Node start, Node target)
{
    var queue   = new Queue<Node>();
    var visited = new HashSet<Node>();
    queue.Enqueue(start);
    visited.Add(start);
    int step = 0;

    while (queue.Count > 0)
    {
        int sz = queue.Count;
        // 把当前层的节点全部处理（每处理一层 step + 1）
        for (int i = 0; i < sz; i++)
        {
            var cur = queue.Dequeue();
            if (cur == target) return step; // 到达终点
            foreach (var next in cur.Neighbors)
            {
                if (!visited.Contains(next))
                {
                    queue.Enqueue(next);
                    visited.Add(next);
                }
            }
        }
        step++;
    }
    return -1; // 无法到达
}
```

#### LeetCode 111. 二叉树的最小深度

**题目：** 给定一个二叉树，找出其最小深度（根节点到最近叶子节点的最短路径上的节点数量）。

**思路：** BFS 层序遍历，第一次遇到**叶子节点**（左右子节点均为 null）时，当前层数即为最小深度。

```csharp
public int MinDepth(TreeNode root)
{
    if (root == null) return 0;
    var queue = new Queue<TreeNode>();
    queue.Enqueue(root);
    int depth = 1;
    while (queue.Count > 0)
    {
        int sz = queue.Count;
        for (int i = 0; i < sz; i++)
        {
            var node = queue.Dequeue();
            // 叶子节点：左右子节点都为 null
            if (node.left == null && node.right == null) return depth;
            if (node.left  != null) queue.Enqueue(node.left);
            if (node.right != null) queue.Enqueue(node.right);
        }
        depth++;
    }
    return depth;
}
```

#### ⭐ LeetCode 752. 打开转盘锁

**题目：** 你有一个带有四个圆形拨轮的转盘锁，每个拨轮都有0-9十个数字，初始数字为 `'0000'`。每次旋转，可以将其中一个拨轮向上或向下拨一个数字（0 和 9 是相邻的）。锁上有一个死亡数字列表 `deadends`，一旦拨轮的数字变成其中一个，锁会被永久锁死。请返回从初始状态拨到目标数字 `target` 的**最少旋转次数**，如果无法解锁，返回 -1。

**思路：** 把每个状态（四位字符串）看作图中的节点，每次拨动产生8个相邻节点（4位×2方向），BFS 找最短路径。

```csharp
public int OpenLock(string[] deadends, string target)
{
    var dead    = new HashSet<string>(deadends);
    var visited = new HashSet<string> { "0000" };
    if (dead.Contains("0000")) return -1;

    var queue = new Queue<string>();
    queue.Enqueue("0000");
    int step = 0;

    while (queue.Count > 0)
    {
        int sz = queue.Count;
        for (int i = 0; i < sz; i++)
        {
            string cur = queue.Dequeue();
            if (cur == target) return step;

            // 对每一位拨轮，分别尝试 +1 和 -1
            for (int j = 0; j < 4; j++)
            {
                foreach (int d in new[] { 1, -1 })
                {
                    char[] arr = cur.ToCharArray();
                    arr[j] = (char)(((arr[j] - '0' + d + 10) % 10) + '0');
                    string next = new string(arr);
                    if (!visited.Contains(next) && !dead.Contains(next))
                    {
                        queue.Enqueue(next);
                        visited.Add(next);
                    }
                }
            }
        }
        step++;
    }
    return -1;
}
```

## 十一、回溯算法

### 📖 教程讲解

**来源文章**：《回溯算法解题套路框架》  
🔗 https://labuladong.online/zh/algo/essential-technique/backtrack-framework/

#### 回溯算法的本质

回溯算法本质是遍历一棵**决策树**，关注点在节点间的**树枝**（每条树枝代表一次「选择」）。

**三个核心要素：**
1. **路径（track）**：已经做出的选择
2. **选择列表**：当前可以做的选择
3. **结束条件**：到达决策树底层（满足题意）

**框架代码：**
```
result = []
def backtrack(路径, 选择列表):
    if 满足结束条件:
        result.add(路径)
        return
    for 选择 in 选择列表:
        做选择
        backtrack(路径, 选择列表)
        撤销选择
```

**本质是多叉树的遍历：** 「做选择」在 for 循环内、递归之前；「撤销选择」在 for 循环内、递归之后。这就是为什么 `track.Add()` 和 `track.Remove()` 总是成对出现。

#### 排列/组合/子集的区别

三类回溯问题的核心区别：

| 类型 | 是否有顺序 | 用什么控制重复 |
|------|-----------|--------------|
| **子集/组合** | 无序 | `start` 参数，只向后取 |
| **排列** | 有序 | `used` 数组，标记已选 |
| **去重** | — | 排序 + `if i > start && nums[i] == nums[i-1] continue` |

#### 剪枝技巧

回溯的效率关键在于剪枝，常见剪枝：
- 组合问题：若剩余元素不够凑满 `k` 个就提前返回
- 有重复元素：排序后跳过 `nums[i] == nums[i-1]` 的情况
- 路径超出限制：当当前路径的和已超过目标值，提前返回

#### ⭐ LeetCode 46. 全排列

**题目：** 给定一个不含重复数字的数组 `nums`，返回其所有可能的**全排列**。

**思路：** 用 `used` 数组标记已选元素，每次从全量元素中选未被使用的，`track` 存当前路径。长度等于 `nums.Length` 时记录结果。

```csharp
public IList<IList<int>> Permute(int[] nums)
{
    var res   = new List<IList<int>>();
    var track = new List<int>();
    var used  = new bool[nums.Length];

    void Backtrack()
    {
        if (track.Count == nums.Length) { res.Add(new List<int>(track)); return; }
        for (int i = 0; i < nums.Length; i++)
        {
            if (used[i]) continue;
            used[i] = true;  track.Add(nums[i]);   // 做选择
            Backtrack();
            used[i] = false; track.RemoveAt(track.Count - 1); // 撤销选择
        }
    }
    Backtrack();
    return res;
}
```

#### ⭐ LeetCode 78. 子集

**题目：** 给你一个整数数组 `nums`，数组中的元素**互不相同**。返回该数组所有可能的子集（幂集）。解集**不能**包含重复的子集。

**思路：** 从 `start` 位置向后取元素，每次递归时不需要满足任何结束条件，直接将当前 `track` 加入结果（每个节点都是合法子集）。

```csharp
public IList<IList<int>> Subsets(int[] nums)
{
    var res   = new List<IList<int>>();
    var track = new List<int>();

    void Backtrack(int start)
    {
        res.Add(new List<int>(track)); // 每个节点都是合法子集
        for (int i = start; i < nums.Length; i++)
        {
            track.Add(nums[i]);
            Backtrack(i + 1); // 下一次从 i+1 开始，避免重复
            track.RemoveAt(track.Count - 1);
        }
    }
    Backtrack(0);
    return res;
}
```

#### ⭐ LeetCode 51. N 皇后（Hard）

**题目：** 按照国际象棋的规则，皇后可以攻击与之处在同一行、同列或同一斜线上的棋子。`n` 皇后问题研究的是如何将 `n` 个皇后放置在 `n×n` 的棋盘上，并且使皇后彼此之间不能相互攻击。给你一个整数 `n`，返回所有不同的 **n 皇后问题** 的解决方案。

**思路：** 逐行放置皇后（每行只放一个），用三个 HashSet 分别追踪「已占用的列」「已占用的正对角线（row-col 相同）」「已占用的反对角线（row+col 相同）」，快速判断冲突。

```csharp
public IList<IList<string>> SolveNQueens(int n)
{
    var res   = new List<IList<string>>();
    var board = new char[n][];
    for (int i = 0; i < n; i++) { board[i] = new char[n]; Array.Fill(board[i], '.'); }

    var cols  = new HashSet<int>(); // 已占用的列
    var diag1 = new HashSet<int>(); // 已占用的正对角线（row - col）
    var diag2 = new HashSet<int>(); // 已占用的反对角线（row + col）

    void Backtrack(int row)
    {
        if (row == n)
        {
            res.Add(board.Select(r => new string(r)).ToList());
            return;
        }
        for (int col = 0; col < n; col++)
        {
            // 冲突检测
            if (cols.Contains(col) || diag1.Contains(row - col) || diag2.Contains(row + col))
                continue;
            // 做选择
            board[row][col] = 'Q';
            cols.Add(col); diag1.Add(row - col); diag2.Add(row + col);
            Backtrack(row + 1);
            // 撤销选择
            board[row][col] = '.';
            cols.Remove(col); diag1.Remove(row - col); diag2.Remove(row + col);
        }
    }
    Backtrack(0);
    return res;
}
```

## 十二、动态规划

### 📖 教程讲解

**来源文章**：《动态规划解题套路框架》  
🔗 https://labuladong.online/zh/algo/essential-technique/dynamic-programming-framework/

#### 动态规划的本质

动态规划的本质是**穷举**。通过消除重叠子问题（备忘录/DP table）提高效率，通过最优子结构保证枚举出的是最优解。

**一定要明确三点：**
1. **最优子结构**：子问题的最优解能推出原问题的最优解
2. **重叠子问题**：相同的子问题会反复计算（用备忘录消除）
3. **状态转移方程**：这是核心，穷举的逻辑全在这里

#### 解题步骤（框架思路）

```
# 自顶向下（递归 + 备忘录）
memo = {}
def dp(状态):
    if 状态 in base_case: return base_case[状态]
    if 状态 in memo: return memo[状态]
    for 选择 in 所有选择:
        result = 求最优(result, dp(新状态))
    memo[状态] = result
    return result

# 自底向上（迭代 DP table）
dp[0][0][...] = base_case
for 状态1 in 所有值:
    for 状态2 in 所有值:
        dp[状态1][状态2][...] = 求最优(选择1, 选择2, ...)
```

#### 动态规划 vs 回溯

| | 动态规划 | 回溯算法 |
|--|---------|---------|
| 视角 | 整棵「子树」的最优值 | 节点间的「树枝」（选择） |
| 是否需要撤销 | ❌ 子问题结果直接用 | ✅ 必须撤销选择 |
| 是否有重叠子问题 | ✅ 通常有，用记忆化 | ❌ 通常每条路径唯一 |

#### ⭐ LeetCode 322. 零钱兑换

**题目：** 给你一个整数数组 `coins`，代表不同面额的硬币；以及一个整数 `amount`，代表总金额。计算并返回凑成总金额所需的**最少的硬币个数**。如果没有任何一种硬币组合能组成总金额，返回 -1。每种硬币的数量是无限的。

**dp 定义：** `dp[i]` = 凑成金额 `i` 所需最少硬币数  
**base case：** `dp[0] = 0`（金额 0 不需要任何硬币）  
**转移方程：** `dp[i] = min(dp[i - coin] + 1)` for each `coin <= i`

```csharp
public int CoinChange(int[] coins, int amount)
{
    int[] dp = new int[amount + 1];
    Array.Fill(dp, amount + 1); // 初始化为不可能的大值（amount+1 > 最多硬币数）
    dp[0] = 0; // base case
    for (int i = 1; i <= amount; i++)
        foreach (int coin in coins)
            if (i >= coin)
                dp[i] = Math.Min(dp[i], dp[i - coin] + 1);
    return dp[amount] > amount ? -1 : dp[amount];
}
```

#### ⭐ LeetCode 300. 最长递增子序列（LIS）

**题目：** 给你一个整数数组 `nums`，找到其中最长严格递增子序列的长度。**子序列**是由数组派生而来的序列，删除（或不删除）数组中的元素而不改变其余元素的顺序。

**dp 定义：** `dp[i]` = 以 `nums[i]` 结尾的最长递增子序列长度  
**base case：** `dp[i] = 1`（每个元素本身就是长度为 1 的子序列）  
**转移方程：** `dp[i] = max(dp[j] + 1)` for all `j < i && nums[j] < nums[i]`

```csharp
public int LengthOfLIS(int[] nums)
{
    int n = nums.Length;
    int[] dp = new int[n];
    Array.Fill(dp, 1); // base case
    for (int i = 1; i < n; i++)
        for (int j = 0; j < i; j++)
            if (nums[j] < nums[i])
                dp[i] = Math.Max(dp[i], dp[j] + 1);
    return dp.Max();
}
```

#### ⭐ LeetCode 1143. 最长公共子序列（LCS）

**题目：** 给定两个字符串 `text1` 和 `text2`，返回这两个字符串的最长**公共子序列**的长度。如果不存在，返回 0。

**dp 定义：** `dp[i][j]` = `text1[0..i-1]` 和 `text2[0..j-1]` 的 LCS 长度  
**转移方程：**  
- 若 `text1[i-1] == text2[j-1]`：`dp[i][j] = dp[i-1][j-1] + 1`
- 否则：`dp[i][j] = max(dp[i-1][j], dp[i][j-1])`

```csharp
public int LongestCommonSubsequence(string text1, string text2)
{
    int m = text1.Length, n = text2.Length;
    int[,] dp = new int[m + 1, n + 1]; // base case 全为 0
    for (int i = 1; i <= m; i++)
        for (int j = 1; j <= n; j++)
            dp[i, j] = text1[i - 1] == text2[j - 1]
                ? dp[i - 1, j - 1] + 1
                : Math.Max(dp[i - 1, j], dp[i, j - 1]);
    return dp[m, n];
}
```

#### ⭐ LeetCode 72. 编辑距离（Hard）

**题目：** 给你两个单词 `word1` 和 `word2`，请返回将 `word1` 转换成 `word2` 所使用的**最少操作数**（可进行插入、删除、替换三种操作）。

**dp 定义：** `dp[i][j]` = 将 `word1[0..i-1]` 转换为 `word2[0..j-1]` 的最少操作数  
**base case：** `dp[i][0] = i`（删除 i 个字符），`dp[0][j] = j`（插入 j 个字符）  
**转移方程：**  
- 若 `word1[i-1] == word2[j-1]`：字符相同，不需要操作，`dp[i][j] = dp[i-1][j-1]`
- 否则：三种操作取最小值：
  - 替换：`dp[i-1][j-1] + 1`
  - 删除 word1[i-1]：`dp[i-1][j] + 1`
  - 在 word1 中插入 word2[j-1]：`dp[i][j-1] + 1`

```csharp
public int MinDistance(string word1, string word2)
{
    int m = word1.Length, n = word2.Length;
    int[,] dp = new int[m + 1, n + 1];
    for (int i = 0; i <= m; i++) dp[i, 0] = i;
    for (int j = 0; j <= n; j++) dp[0, j] = j;
    for (int i = 1; i <= m; i++)
        for (int j = 1; j <= n; j++)
            dp[i, j] = word1[i - 1] == word2[j - 1]
                ? dp[i - 1, j - 1]
                : 1 + Math.Min(dp[i - 1, j - 1],
                      Math.Min(dp[i - 1, j], dp[i, j - 1]));
    return dp[m, n];
}
```

## 十三、图论基础：DFS 与拓扑排序

### 📖 教程讲解

**来源文章**：《图论算法基础》  
🔗 https://labuladong.online/zh/algo/data-structure/graph-traverse/

#### 图与二叉树的关系

图就是多叉树（多了「可以有环」这个特性），图的 DFS 遍历与多叉树的遍历几乎相同，只是多了 `visited` 数组防止重复访问。

图的 DFS 框架：进入节点时标记 `onPath`（当前路径），退出时取消，可以检测环；进入时标记 `visited`（已访问），不需要取消，用于防重复遍历。

**有向图判环（DFS）：** 用 `onPath` 追踪当前递归路径，若访问到 `onPath` 中的节点则说明有环（形成了回路）。

#### 拓扑排序

拓扑排序只适用于**有向无环图（DAG）**，将有依赖关系的节点排成线性序列（所有指向关系都从前向后）。

**Kahn 算法（BFS）：**
1. 计算所有节点的入度
2. 将入度为 0 的节点入队
3. 每处理一个节点，将其邻居的入度减 1，若变为 0 则入队
4. 处理完所有节点若 count == 总节点数，则无环（且 order 即为拓扑序）

### 📝 习题详解

#### ⭐ LeetCode 207. 课程表

**题目：** 你这个学期必须选修 `numCourses` 门课程，课程按 0 到 `numCourses-1` 编号。给你一个数组 `prerequisites`，`prerequisites[i] = [a, b]` 表示如果要学习课程 `a`，需要先完成课程 `b`。请你判断是否可能完成所有课程的学习？（即是否存在循环依赖）

**思路：** 建有向图，用 Kahn 算法拓扑排序，判断是否所有节点都被处理到。

```csharp
public bool CanFinish(int numCourses, int[][] prerequisites)
{
    int[] inDegree = new int[numCourses];
    var adj = Enumerable.Range(0, numCourses).Select(_ => new List<int>()).ToArray();
    foreach (var p in prerequisites)
    {
        adj[p[1]].Add(p[0]); // p[1] → p[0]（先修 p[1] 才能学 p[0]）
        inDegree[p[0]]++;
    }
    var queue = new Queue<int>();
    for (int i = 0; i < numCourses; i++)
        if (inDegree[i] == 0) queue.Enqueue(i); // 入度为 0 的课程先上
    int count = 0;
    while (queue.Count > 0)
    {
        int node = queue.Dequeue(); count++;
        foreach (int next in adj[node])
            if (--inDegree[next] == 0) queue.Enqueue(next);
    }
    return count == numCourses; // 能处理完所有课程，说明无环
}
```

```csharp
public int NumIslands(char[][] grid)

void Flood(char[][] grid, int i, int j)

    if (i < 0 || j < 0 || i >= grid.Length || j >= grid[0].Length) return;

    grid[i][j] = '0'; // 淹没当前格

    Flood(grid, i, j + 1); Flood(grid, i, j - 1);
}
```

## 十四、最短路径：Dijkstra

### 📖 教程讲解

**来源文章**：《Dijkstra 算法模板及应用》  
🔗 https://labuladong.online/zh/algo/essential-technique/dijkstra/

#### Dijkstra 算法原理

Dijkstra 是求**有权图（非负权边）单源最短路径**的经典算法，核心思想是「贪心 + 松弛」：

1. 维护 `dist` 数组，`dist[i]` = 从源点到节点 `i` 的当前最短估计距离
2. 每次从优先队列中取出**当前距离最小的节点**
3. 对其所有邻居进行**松弛操作**：若经过当前节点能获得更短路径，则更新 `dist`

**关键优化：** 同一节点可能多次进入优先队列（因为先入队时用的是旧距离）。处理时检查 `if d > dist[node] continue` 跳过过期状态。

**时间复杂度：** O((V+E) log V)（V 为节点数，E 为边数）

#### 代码模板

~~~c#
using System;
using System.Collections.Generic;

// 定义边的结构
public class Edge {
    public int To { get; set; }
    public int Weight { get; set; }

    public Edge(int to, int weight) {
        To = to;
        Weight = weight;
    }
}

// 定义图结构接口（根据你的实际实现调整）
public class Graph {
    private List<List<Edge>> adjList;

    public Graph(int n) {
        adjList = new List<List<Edge>>(n);
        for (int i = 0; i < n; i++) {
            adjList.Add(new List<Edge>());
        }
    }

    public void AddEdge(int from, int to, int weight) {
        adjList[from].Add(new Edge(to, weight));
    }

    public int Size() {
        return adjList.Count;
    }

    public List<Edge> Neighbors(int node) {
        return adjList[node];
    }
}

// 记录队列中的状态
public class State {
    public int Node { get; set; }
    public int DistFromStart { get; set; }

    public State(int node, int distFromStart) {
        Node = node;
        DistFromStart = distFromStart;
    }
}

public class Solution {
    // 输入不包含负权重边的加权图 graph 和起点 src
    // 返回从起点 src 到其他节点的最小路径权重和
    public int[] Dijkstra(Graph graph, int src) {
        int n = graph.Size();
        
        // 记录从起点 src 到其他节点的最小路径权重和
        // distTo[i] 表示从起点 src 到节点 i 的最小路径权重和
        int[] distTo = new int[n];
        Array.Fill(distTo, int.MaxValue);

        // 优先级队列
        // C# PriorityQueue 默认是最小堆，即 Priority 小的先出队
        // 这里 Element 是 State，Priority 是 distFromStart
        var pq = new PriorityQueue<State, int>();

        // 从起点 src 开始进行 BFS
        pq.Enqueue(new State(src, 0), 0);
        distTo[src] = 0;

        while (pq.Count > 0) {
            State state = pq.Dequeue();
            int curNode = state.Node;
            int curDistFromStart = state.DistFromStart;

            // 剪枝：如果当前取出的距离大于已记录的最短距离，说明是过期状态，跳过
            if (distTo[curNode] < curDistFromStart) {
                continue;
            }

            foreach (Edge e in graph.Neighbors(curNode)) {
                int nextNode = e.To;
                int nextDistFromStart = curDistFromStart + e.Weight;

                // 如果找到更短的路径，则更新
                if (distTo[nextNode] > nextDistFromStart) {
                    // 将 nextNode 节点加入优先级队列
                    pq.Enqueue(new State(nextNode, nextDistFromStart), nextDistFromStart);
                    // 记录 nextNode 节点到起点的最小路径权重和
                    distTo[nextNode] = nextDistFromStart;
                }
            }
        }

        return distTo;
    }
}
~~~

#### ⭐ LeetCode 743. 网络延迟时间

**题目：** 有 `n` 个网络节点，编号 1 到 n。给你一个列表 `times`，表示信号经过**有向边** `times[i] = (u, v, w)` 的时间。现在，从某个节点 `k` 发出一个信号。返回使所有节点都收到信号所需的**最少时间**；如果不能使所有节点收到信号，返回 -1。

**思路：** Dijkstra 从 `k` 出发求所有节点最短路径，返回最大值（最后一个节点收到信号的时间）。

```csharp
public int NetworkDelayTime(int[][] times, int n, int k)
{
    // 建图（邻接表）
    var graph = new List<(int to, int w)>[n + 1];
    for (int i = 0; i <= n; i++) graph[i] = new List<(int, int)>();
    foreach (var t in times) graph[t[0]].Add((t[1], t[2]));

    // Dijkstra
    var dist = new int[n + 1];
    Array.Fill(dist, int.MaxValue);
    dist[k] = 0;
    var pq = new PriorityQueue<int, int>(); // (节点, 到该节点的距离)
    pq.Enqueue(k, 0);

    while (pq.Count > 0)
    {
        pq.TryDequeue(out int node, out int d);
        if (d > dist[node]) continue; // 过期状态，跳过
        foreach (var (to, w) in graph[node])
        {
            int newDist = dist[node] + w;
            if (newDist < dist[to])
            {
                dist[to] = newDist;
                pq.Enqueue(to, newDist);
            }
        }
    }
    int ans = dist.Skip(1).Max(); // 取所有节点最短路径的最大值
    return ans == int.MaxValue ? -1 : ans;
}
```

## 十五、单调栈

### 📖 教程讲解

**来源文章**：《单调栈算法模板解题框架》  
🔗 https://labuladong.online/zh/algo/data-structure/monotonic-stack/

#### 单调栈的用途

单调栈专门解决「**下一个更大/更小元素**」类问题，时间复杂度 O(N)（每个元素最多入栈/出栈各一次）。

**单调递减栈（求下一个更大元素）：**

从后往前遍历，维护一个单调递减的栈（栈底大、栈顶小）。对每个元素，将所有比它**小或等于**的栈顶弹出，栈顶就是它右侧第一个更大的元素。

**从前往后也可以：** 遇到比栈顶更大的元素时，弹出栈顶并记录答案（栈顶的「下一个更大元素」就是当前元素）。

### 📝 习题详解

#### ⭐ LeetCode 739. 每日温度

**题目：** 给定一个整数数组 `temperatures`，表示每天的温度，返回一个数组 `answer`，其中 `answer[i]` 是指对于第 `i` 天，下一个更高温度出现在几天后。如果气温在这之后都不会升高，请在该位置用 0 来代替。

**思路：** 单调栈（存下标），从前往后遍历，遇到更高温度时弹出栈中较小温度并记录距离。

```csharp
public int[] DailyTemperatures(int[] temperatures)
{
    int n = temperatures.Length;
    int[] res = new int[n];
    var stack = new Stack<int>(); // 存下标，栈内对应温度单调递减

    for (int i = 0; i < n; i++)
    {
        // 当前温度比栈顶温度高，弹出并记录答案
        while (stack.Count > 0 && temperatures[stack.Peek()] < temperatures[i])
        {
            int idx = stack.Pop();
            res[idx] = i - idx; // 等待天数 = 当前下标 - 弹出下标
        }
        stack.Push(i);
    }
    return res; // 未弹出的下标默认 res 为 0（初始化时已为 0）
}
```

#### ⭐ LeetCode 84. 柱状图中最大的矩形（Hard）

**题目：** 给定 `n` 个非负整数，用来表示柱状图中各个柱子的高度，每个柱子彼此相邻，且宽度为 1。求在该柱状图中，能够勾勒出来的矩形的**最大面积**。

**思路：** 单调递增栈。对每根柱子，找它左边和右边第一根比它矮的柱子，以该柱子为高度的最大矩形宽度就确定了。

```csharp
public int LargestRectangleArea(int[] heights)
{
    int n = heights.Length, maxArea = 0;
    // 在两端加哨兵（高度为 0），避免边界特判
    int[] h = new int[n + 2];
    h[0] = h[n + 1] = 0;
    Array.Copy(heights, 0, h, 1, n);
    n += 2;

    var stack = new Stack<int>(); // 单调递增栈（存下标）
    stack.Push(0);
    for (int i = 1; i < n; i++)
    {
        while (h[stack.Peek()] > h[i]) // 当前柱子比栈顶矮，栈顶柱子的右边界确定
        {
            int height = h[stack.Pop()];
            int width  = i - stack.Peek() - 1; // 左边界由新栈顶决定
            maxArea = Math.Max(maxArea, height * width);
        }
        stack.Push(i);
    }
    return maxArea;
}
```

## 十六、二叉搜索树 BST

### 📖 教程讲解

**来源文章**：《东哥带你刷二叉搜索树（基础篇）》  
🔗 https://labuladong.online/zh/algo/data-structure/bst-part1/

#### BST 的核心性质

- **左子树 < 根 < 右子树**（严格递增）
- **BST 的中序遍历 = 升序序列**（这是 BST 最重要的性质）
- 查找/插入/删除：平均 O(log n)，最坏 O(n)（退化为链表时）

**利用 BST 有序性的搜索：**

普通二叉树搜索需要遍历全树，BST 可以根据大小关系裁剪搜索空间：
- `target < root.val` → 只在左子树搜索
- `target > root.val` → 只在右子树搜索

**BST 删除的难点：**

删除叶节点或单侧子树节点很容易；难的是删除**两侧都有子树**的节点，需要找「中序后继」（右子树中最小的节点）来替代被删节点，同时维持 BST 性质。

---

### 📝 习题详解

#### ⭐ LeetCode 450. 删除二叉搜索树中的节点

**题目：** 给定一个二叉搜索树的根节点 `root` 和一个值 `key`，删除 BST 中的节点值为 `key` 的节点，并保证 BST 的性质不变。返回 BST（有可能被更新）的根节点的引用。

```csharp
public TreeNode DeleteNode(TreeNode root, int key)
{
    if (root == null) return null;
    if (key < root.val)
        root.left = DeleteNode(root.left, key);
    else if (key > root.val)
        root.right = DeleteNode(root.right, key);
    else // 找到了要删除的节点
    {
        if (root.left == null)  return root.right; // 情况 1：无左子树
        if (root.right == null) return root.left;  // 情况 2：无右子树
        // 情况 3：左右子树都有 → 找右子树最小节点（中序后继）替代
        var minNode = root.right;
        while (minNode.left != null) minNode = minNode.left;
        root.right = DeleteNode(root.right, minNode.val); // 删除后继节点
        minNode.left  = root.left;
        minNode.right = root.right;
        root = minNode;
    }
    return root;
}
```

#### LeetCode 230. 二叉搜索树中第 K 小的元素

**题目：** 给定一个二叉搜索树的根节点 `root`，和一个整数 `k`，请你设计一个算法查找其中第 `k` 小的元素（从 1 开始计数）。

**思路：** BST 中序遍历得到升序序列，第 k 次访问的节点即为第 k 小。

```csharp
public int KthSmallest(TreeNode root, int k)
{
    int res = 0, count = 0;
    void Inorder(TreeNode node)
    {
        if (node == null) return;
        Inorder(node.left);
        if (++count == k) { res = node.val; return; } // 第 k 次访问
        Inorder(node.right);
    }
    Inorder(root);
    return res;
}
```

## 十七、堆与优先队列

### 📖 教程讲解

**来源文章**：《二叉堆实现优先级队列》  
🔗 https://labuladong.online/zh/algo/data-structure/binary-heap-implements-priority-queues/

#### 堆的核心性质

堆是完全二叉树的数组实现：
- **大顶堆**：父节点 ≥ 子节点，堆顶是最大值
- **小顶堆**：父节点 ≤ 子节点，堆顶是最小值

**C# 中的 `PriorityQueue<TElement, TPriority>`（.NET 6+）：** 默认小顶堆，按 `TPriority` 升序出队。

**典型应用：**
- **Top K 大**：维护大小为 K 的小顶堆，遍历时超过 K 则弹出堆顶（弹出最小值）
- **Top K 小**：维护大小为 K 的大顶堆，遍历时超过 K 则弹出堆顶（弹出最大值）
- **实时中位数**：大顶堆存较小一半，小顶堆存较大一半，维护两堆大小差 ≤ 1

### 📝 习题详解

#### ⭐ LeetCode 215. 数组中的第 K 个最大元素

**题目：** 给定整数数组 `nums` 和整数 `k`，请返回数组中第 `k` 个最大的元素。

**思路：** 维护大小为 k 的小顶堆，遍历完成后堆顶就是第 k 大元素。

```csharp
public int FindKthLargest(int[] nums, int k)
{
    var pq = new PriorityQueue<int, int>(); // 小顶堆
    foreach (int num in nums)
    {
        pq.Enqueue(num, num);
        if (pq.Count > k) pq.Dequeue(); // 堆超过 k 个，弹出最小值
    }
    return pq.Peek(); // 堆顶即第 k 大
}
```

#### LeetCode 295. 数据流的中位数（Hard）

**题目：** 中位数是有序整数列表中间的数。设计一个支持以下两种操作的数据结构：`addNum(int num)` 将数据流中的整数 `num` 添加到数据结构中；`findMedian()` 返回目前所有元素的中位数。

**思路：** 大顶堆 `lo`（存较小的一半）+ 小顶堆 `hi`（存较大的一半），每次 `addNum` 后平衡两堆大小差不超过 1。

```csharp
public class MedianFinder
{
    // lo: 大顶堆（用负数模拟，C# PriorityQueue 默认小顶堆）
    private PriorityQueue<int, int> lo = new();
    // hi: 小顶堆
    private PriorityQueue<int, int> hi = new();

    public void AddNum(int num)
    {
        // 先加入大顶堆，再把大顶堆堆顶移入小顶堆（保证 lo 所有元素 ≤ hi 所有元素）
        lo.Enqueue(num, -num); // 负数模拟大顶堆
        hi.Enqueue(lo.Peek(), lo.Peek()); lo.Dequeue();
        // 平衡两堆大小：lo 的大小不能比 hi 小
        if (hi.Count > lo.Count)
        {
            lo.Enqueue(hi.Peek(), -hi.Peek()); hi.Dequeue();
        }
    }

    public double FindMedian()
    {
        // lo 多一个元素时，中位数是 lo 的堆顶
        // 两堆大小相等时，中位数是两堆顶的平均值
        return lo.Count > hi.Count
            ? lo.Peek()
            : (lo.Peek() + hi.Peek()) / 2.0;
    }
}
```

## 十八、循环数组与单调队列

### 📖 教程讲解

**来源文章**：《单调队列结构解决滑动窗口问题》  
🔗 https://labuladong.online/zh/algo/data-structure/monotonic-queue/

#### 循环数组的技巧

循环数组用 `(i + 1) % n` 实现下标的环绕，让数组首尾相连，常用于「下一个更大元素 II」（503 题）等需要绕圈遍历的场景。

处理循环数组的通用技巧：**将数组长度翻倍（或虚拟翻倍）**，用 `i % n` 取模来映射回原数组：

```
遍历 [0, 2n-1]，访问 nums[i % n]
```

这样 `i` 超过 `n` 后会自动绕回数组头部，等价于两圈遍历。

#### 单调队列的核心思想

单调队列（双端队列 Deque）解决的是「**滑动窗口内的最值**」问题，时间复杂度 O(N)。

**关键性质：** 队列内元素保持单调递减（从队头到队尾），队头始终是当前窗口的最大值。

**入队操作：** 新元素从队尾入队前，先将所有比新元素**小**的队尾元素弹出（它们在新元素存活期间永远不可能成为最大值，直接淘汰）。

**出队操作：** 当窗口左边界移动时，如果队头元素恰好是被移出窗口的那个元素，则将队头弹出。

**为什么正确？** 单调队列中，每个元素都代表「到目前为止可能成为后续窗口最大值的候选」。较小的元素一旦被更大的新元素覆盖，就永远没有机会成为最大值，可以提前淘汰。

---

### 🧩 代码模板（C#）

```csharp
// LeetCode 239. 滑动窗口最大值
// 单调队列：存下标，队头对应的 nums 值始终是当前窗口最大值
public int[] MaxSlidingWindow(int[] nums, int k)
{
    int n = nums.Length;
    var res = new int[n - k + 1];
    // 双端队列，存下标，队内元素对应的 nums 值单调递减
    var deque = new LinkedList<int>();

    for (int i = 0; i < n; i++)
    {
        // 1. 移除不在当前窗口 [i-k+1, i] 内的队头
        while (deque.Count > 0 && deque.First!.Value < i - k + 1)
            deque.RemoveFirst();

        // 2. 维护单调性：移除所有比 nums[i] 小的队尾（它们已无用）
        while (deque.Count > 0 && nums[deque.Last!.Value] < nums[i])
            deque.RemoveLast();

        deque.AddLast(i);

        // 3. 窗口形成后记录答案（队头即窗口最大值的下标）
        if (i >= k - 1)
            res[i - k + 1] = nums[deque.First!.Value];
    }
    return res;
}
```

#### ⭐ LeetCode 239. 滑动窗口最大值（Hard）

**题目：** 给你一个整数数组 `nums`，有一个大小为 `k` 的滑动窗口从数组的最左侧移动到数组的最右侧。你只可以看到在滑动窗口内的 `k` 个数字。滑动窗口每次只向右移动一位。返回**滑动窗口中的最大值**。

**思路：** 单调队列存下标，队头维护窗口内最大值的下标。每次右扩时：先清理过期队头，再清理比新元素小的队尾，最后将新下标入队。见上方模板。

#### LeetCode 503. 下一个更大元素 II

**题目：** 给定一个循环数组 `nums`（`nums[nums.length - 1]` 的下一个元素是 `nums[0]`），返回 `nums` 中每个元素的**下一个更大元素**。不存在则输出 -1。

**思路：** 循环数组用「虚拟翻倍」处理，遍历 `[0, 2n-1]`，用 `i % n` 取模访问元素。同时维护单调栈存下标。

```csharp
public int[] NextGreaterElements(int[] nums)
{
    int n = nums.Length;
    int[] res = new int[n];
    Array.Fill(res, -1);
    var stack = new Stack<int>(); // 存下标（原始下标）

    // 虚拟遍历两圈
    for (int i = 0; i < 2 * n; i++)
    {
        // 当前元素比栈顶对应元素大，则栈顶找到了「下一个更大元素」
        while (stack.Count > 0 && nums[stack.Peek()] < nums[i % n])
            res[stack.Pop()] = nums[i % n];

        // 只在第一圈入栈（避免重复）
        if (i < n) stack.Push(i);
    }
    return res;
}
```

## 十九、栈与队列

### 📖 教程讲解

**来源文章**：《栈与队列的相互实现》  
🔗 https://labuladong.online/zh/algo/data-structure/stack-and-queue/

#### 栈与队列的本质区别

- **栈（Stack）**：后进先出（LIFO），只允许在栈顶操作。类比「叠盘子」。
- **队列（Queue）**：先进先出（FIFO），一端入队另一端出队。类比「排队买票」。

这两种数据结构看似相反，但可以互相模拟，这揭示了它们的内在联系。

#### 用两个栈模拟队列

思路：一个栈 `s1` 负责「入队」，另一个栈 `s2` 负责「出队」。  
当 `s2` 为空时，将 `s1` 的全部元素转移到 `s2`（顺序倒转，实现先进先出）。  
这样每个元素最多被转移一次，均摊时间复杂度 O(1)。

#### 用两个队列模拟栈

思路：保持一个队列为「主队列」存所有元素。  
每次「出栈」（取最后入队的元素）时，将主队列除最后一个元素外全部转移到辅助队列，取出最后那个，再将辅助队列转回主队列。  
时间复杂度 O(N)。

#### 单调栈 vs 单调队列

| | 单调栈 | 单调队列 |
|--|--------|---------|
| 数据结构 | 栈 | 双端队列 |
| 解决的问题 | 下一个更大/小元素 | 滑动窗口最值 |
| 单调方向 | 栈内单调递增/递减 | 队内单调递减（求最大） |
| 操作复杂度 | O(N) 总计 | O(N) 总计 |

### 🧩 代码模板（C#）

```csharp
// 用两个栈实现队列（LeetCode 232）
public class MyQueue
{
    private Stack<int> s1 = new(); // 入队栈
    private Stack<int> s2 = new(); // 出队栈

    public void Push(int x) => s1.Push(x);

    public int Pop()
    {
        if (s2.Count == 0)
            while (s1.Count > 0) s2.Push(s1.Pop()); // s1 全部倒入 s2
        return s2.Pop();
    }

    public int Peek()
    {
        if (s2.Count == 0)
            while (s1.Count > 0) s2.Push(s1.Pop());
        return s2.Peek();
    }

    public bool Empty() => s1.Count == 0 && s2.Count == 0;
}

// 用两个队列实现栈（LeetCode 225）
public class MyStack
{
    private Queue<int> q = new();

    public void Push(int x)
    {
        q.Enqueue(x);
        // 把之前所有元素移到新元素后面（新元素变为队头）
        for (int i = 0; i < q.Count - 1; i++)
            q.Enqueue(q.Dequeue());
    }

    public int Pop()  => q.Dequeue();
    public int Top()  => q.Peek();
    public bool Empty() => q.Count == 0;
}
```

#### ⭐ LeetCode 42. 接雨水（Hard）

**题目：** 给定 `n` 个非负整数表示每个宽度为 1 的柱子的高度图，计算按此排列的柱子，下雨之后能接多少雨水。

**思路（双指针）：** 维护左右指针和左右最大高度。某位置能接的水 = `min(leftMax, rightMax) - height[i]`。每次移动较矮一侧的指针（因为决定积水量的是较矮的那侧）。

```csharp
public int Trap(int[] height)
{
    int left = 0, right = height.Length - 1;
    int leftMax = 0, rightMax = 0, res = 0;
    while (left < right)
    {
        leftMax  = Math.Max(leftMax,  height[left]);
        rightMax = Math.Max(rightMax, height[right]);
        // 移动较矮的一侧，该侧积水量已确定
        if (leftMax < rightMax)
            res += leftMax - height[left++];   // 左侧积水
        else
            res += rightMax - height[right--]; // 右侧积水
    }
    return res;
}
```

## 二十、哈希表

### 📖 教程讲解

**来源文章**：《哈希表的原理及实现》  
🔗 https://labuladong.online/zh/algo/data-structure/hash-function/

#### 哈希表的核心原理

哈希表（散列表）提供均摊 O(1) 的增删查，是「空间换时间」的代表数据结构。

**核心组成：**
1. **哈希函数**：将 key 映射到数组下标，好的哈希函数能均匀分布，减少碰撞
2. **碰撞解决**：两个 key 映射到同一下标时需要解决冲突
   - **拉链法（链地址法）**：每个桶是一个链表，冲突的元素追加到链表末尾
   - **线性探测法（开放地址法）**：冲突时向后探测空位

**负载因子（Load Factor）：** `n / capacity`（已有元素数 / 总容量）。负载因子过高时触发扩容（通常阈值为 0.75），扩容后重新哈希所有元素，均摊后每次操作仍是 O(1)。

#### 哈希表的典型应用模式

1. **频率/计数**：统计字符或元素出现次数
2. **快速判断存在性**：用 `HashSet` 替代线性扫描
3. **映射关系**：`key → value` 的双向关联
4. **前缀和 + 哈希**：解决子数组/子串求和问题（如 560 题）
5. **两数之和**：遍历时用哈希表查找 `target - num`

#### C# 中的哈希相关数据结构

| 类型 | C# 类 | 特点 |
|------|--------|------|
| 哈希表 | `Dictionary<K,V>` | key-value 映射，O(1) 增删查 |
| 哈希集合 | `HashSet<T>` | 只存 key，O(1) 判断存在 |
| 有序映射 | `SortedDictionary<K,V>` | 基于红黑树，O(log n)，key 有序 |
| 有序集合 | `SortedSet<T>` | 基于红黑树，O(log n) |

#### ⭐ LeetCode 1. 两数之和

**题目：** 给定一个整数数组 `nums` 和一个整数目标值 `target`，请在该数组中找出**和为目标值**的那两个整数，并返回它们的数组下标。每种输入只会对应一个答案，且同一个元素不能使用两遍。

**思路：** 遍历数组，对每个 `nums[i]`，用哈希表查找是否已存在 `target - nums[i]`，若存在直接返回，否则将 `nums[i]` 记入哈希表。O(N) 时间，O(N) 空间。

```csharp
public int[] TwoSum(int[] nums, int target)
{
    var map = new Dictionary<int, int>(); // key: 数值, value: 下标
    for (int i = 0; i < nums.Length; i++)
    {
        int complement = target - nums[i];
        if (map.ContainsKey(complement))
            return new int[] { map[complement], i };
        map[nums[i]] = i;
    }
    return Array.Empty<int>();
}
```

#### ⭐ LeetCode 128. 最长连续序列

**题目：** 给定一个未排序的整数数组 `nums`，找出数字连续的最长序列（不要求序列元素在原数组中连续）的长度。要求 O(N) 时间复杂度。

**思路：** 将所有数放入 `HashSet`。对每个数 `num`，只在 `num-1` **不在** Set 中时（即 `num` 是序列起点），才开始向后连续查找，统计长度。这样每个数最多被查询两次，总时间 O(N)。

```csharp
public int LongestConsecutive(int[] nums)
{
    var set = new HashSet<int>(nums);
    int maxLen = 0;
    foreach (int num in set)
    {
        // 只从序列起点开始计数，避免重复计算
        if (set.Contains(num - 1)) continue;
        int cur = num, len = 1;
        while (set.Contains(cur + 1)) { cur++; len++; }
        maxLen = Math.Max(maxLen, len);
    }
    return maxLen;
}
```

### 📖 教程讲解

**来源文章**：《算法就像搭乐高：手把手带你拆解 LRU 算法》  
🔗 https://labuladong.online/zh/algo/data-structure/lru-cache/

#### LRU 缓存的设计思路

LRU（Least Recently Used，最近最少使用）缓存淘汰策略：当缓存满时，淘汰最久未被使用的那个数据。

**核心要求：**
- `get(key)` 和 `put(key, val)` 都要求 **O(1)** 时间复杂度
- 每次访问（get/put）后，对应 key 要成为「最近使用」

**为什么需要哈希表 + 双向链表？**

- **哈希表**：O(1) 定位 key 对应的链表节点
- **双向链表**：O(1) 移动节点到头部（需要知道前驱节点，所以用双向而非单向）
- **链表尾部** = 最近使用（最新）；**链表头部** = 最久未使用（最旧），满时从头部删除

**操作逻辑：**
- `get(key)`：在哈希表中找到节点，将其移到链表尾部，返回值
- `put(key, val)`：
  - key 已存在：更新值，移到链表尾部
  - key 不存在：创建新节点加到链表尾部，哈希表记录；若超容，删除链表头部节点并从哈希表移除

---

### 🧩 代码模板（C#）

```csharp
// LeetCode 146. LRU 缓存
public class LRUCache
{
    private int capacity;
    // LinkedList 节点存 (key, val) 便于反向从节点找到 key（删除时需要）
    private LinkedList<(int key, int val)> list = new();
    private Dictionary<int, LinkedListNode<(int key, int val)>> map = new();

    public LRUCache(int capacity) => this.capacity = capacity;

    public int Get(int key)
    {
        if (!map.ContainsKey(key)) return -1;
        var node = map[key];
        // 移到链表尾部（最近使用）
        list.Remove(node);
        list.AddLast(node);
        return node.Value.val;
    }

    public void Put(int key, int value)
    {
        if (map.ContainsKey(key))
        {
            // 已存在：更新值，移到尾部
            list.Remove(map[key]);
            map.Remove(key);
        }
        else if (list.Count == capacity)
        {
            // 超容：删除链表头部（最久未使用）
            map.Remove(list.First!.Value.key);
            list.RemoveFirst();
        }
        // 新节点加到尾部
        list.AddLast((key, value));
        map[key] = list.Last!;
    }
}
```

**题目：** 实现 `RandomizedSet` 类，支持 `insert`、`remove`、`getRandom` 三种操作，时间复杂度均为 O(1)。

**思路：** 哈希表 + 动态数组。数组支持 O(1) 随机访问，哈希表记录每个元素在数组中的下标。删除时将目标元素与数组末尾元素交换，再删末尾（O(1)，避免移位）。

```csharp
public class RandomizedSet
{
    private List<int> nums = new();
    private Dictionary<int, int> map = new(); // val → 在 nums 中的下标
    private Random rand = new();

    public bool Insert(int val)
    {
        if (map.ContainsKey(val)) return false;
        nums.Add(val);
        map[val] = nums.Count - 1;
        return true;
    }

    public bool Remove(int val)
    {
        if (!map.ContainsKey(val)) return false;
        int idx = map[val];
        int last = nums[^1];
        // 将末尾元素移到被删位置
        nums[idx] = last;
        map[last] = idx;
        nums.RemoveAt(nums.Count - 1);
        map.Remove(val);
        return true;
    }

    public int GetRandom() => nums[rand.Next(nums.Count)];
}
```

## 二十二、随机算法

### 📖 教程讲解

**来源文章**：《谁能想到，随机算法也能用于解题》  
🔗 https://labuladong.online/zh/algo/frequency-interview/random-pick-with-weight/

#### 水库采样（Reservoir Sampling）

**问题：** 数据流长度未知（或极大），如何等概率随机取 1 个元素？

**思路：** 对第 `i` 个元素（从 1 开始），以 `1/i` 的概率用它替换当前结果。

**正确性证明（数学归纳）：**
- `i=1`：结果为 1 号元素，概率 1（即 1/1）✓
- `i=k`：第 k 个元素以 `1/k` 概率被选，之前结果以 `1 - 1/k = (k-1)/k` 的概率保留；归纳假设之前每个元素的概率都是 `1/(k-1)`，乘以保留概率得 `1/(k-1) × (k-1)/k = 1/k` ✓

#### Fisher-Yates 洗牌算法

**目标：** 对数组进行**等概率随机全排列**（每种排列的概率均等）。

**思路：** 从末尾向前，每次在 `[0, i]` 随机选一个位置与 `i` 处交换。

**正确性：** 对于 n 个元素，第一个元素排在第 n-1 位的概率 = 第 n-1 轮选中它的概率 = 1/n；排在第 n-2 位的概率 = 第 n-2 轮选中它（1/(n-1)）且第 n-1 轮没选（1 - 1/n = (n-1)/n）= 1/n。以此类推，每个元素排在每个位置的概率均为 1/n，满足等概率。

#### 按权重随机选择

**问题：** 给定权重数组 `w`，按权重概率随机选择一个下标。

**思路：** 构建前缀和数组，在 `[1, sum(w)]` 范围内随机选一个整数，用二分搜索左边界找到对应区间。

---

### 🧩 代码模板（C#）

```csharp
// 水库采样：等概率从数组/流中随机取 1 个
int ReservoirSample(int[] stream)
{
    var rand = new Random();
    int res = stream[0];
    for (int i = 1; i < stream.Length; i++)
        if (rand.Next(i + 1) == 0) // 以 1/(i+1) 的概率替换
            res = stream[i];
    return res;
}

// Fisher-Yates 洗牌（等概率全排列）
void Shuffle(int[] nums)
{
    var rand = new Random();
    for (int i = nums.Length - 1; i > 0; i--)
    {
        int j = rand.Next(i + 1); // [0, i] 随机选一个位置
        (nums[i], nums[j]) = (nums[j], nums[i]);
    }
}

// 按权重随机选择（LeetCode 528）
public class Solution
{
    private int[] preSum;
    private Random rand = new Random();

    public Solution(int[] w)
    {
        preSum = new int[w.Length + 1];
        for (int i = 1; i <= w.Length; i++)
            preSum[i] = preSum[i - 1] + w[i - 1];
    }

    public int PickIndex()
    {
        // 在 [1, total] 随机选整数，二分找到对应区间
        int target = rand.Next(1, preSum[^1] + 1);
        int left = 1, right = preSum.Length - 1;
        while (left < right)
        {
            int mid = left + (right - left) / 2;
            if (preSum[mid] < target) left = mid + 1;
            else right = mid;
        }
        return left - 1; // 转回原数组下标（0-indexed）
    }
}
```

## 二十三、分治算法

### 📖 教程讲解

**来源文章**：《分治算法解题套路框架》  
🔗 https://labuladong.online/zh/algo/essential-technique/divide-and-conquer/

#### 分治思想与分治算法的区别

**分治思想（广义）：** 把问题分解成子问题，递归求解，合并得到答案。这是递归算法的通用模式，斐波那契、二叉树节点计数、动态规划都属于此类。

**分治算法（狭义）：** 在分治思想的基础上，分解求解相比不分解求解有**时间复杂度上的提升**。

**为什么分而治之能降低复杂度？** 以完全平方公式类比：

```
(a + b)² = a² + 2ab + b² ≥ a² + b²
```

如果原问题规模 N = a + b，O(N²) 算法的代价是 (a+b)²。  
分解成两个规模为 a 和 b 的子问题分别求解，代价是 a² + b² < (a+b)²。

因此，**多项式级别复杂度**的算法最有可能通过分治来降低复杂度。

#### 分治的对应思维：二叉树后序遍历

分治算法的递归调用对应二叉树**后序遍历**：先递归处理左右子树（子问题），再在当前节点（后序位置）合并结果。

**归并排序** 是最经典的分治算法：
1. **分**：递归地将数组从中间切分（前序不做事）
2. **治**：在后序位置合并两个有序子数组

归并排序的副产品：可以在合并阶段统计**逆序对**数量（即右半部分元素超越左半部分的次数），这是 315 题的核心思路。

### 📝 习题详解

#### LeetCode 23. 合并 K 个升序链表（Hard）

**题目：** 给你一个链表数组，每个链表都已经按升序排列。请你将所有链表**合并到一个升序链表**中，返回合并后的链表。

**思路（分治）：** 两两合并：先将 k 个链表两两配对，每对调用「合并两个有序链表」，得到 k/2 个链表，再继续两两合并，共 log k 轮，总时间 O(N log k)（N 为所有节点总数）。

也可用**优先队列**：将 k 个链表的头节点加入小顶堆，每次取最小节点接到结果链表，然后将该节点的下一个节点入堆。

```csharp
public ListNode MergeKLists(ListNode[] lists)
{
    if (lists.Length == 0) return null;
    return MergeRange(lists, 0, lists.Length - 1);
}

ListNode MergeRange(ListNode[] lists, int lo, int hi)
{
    if (lo == hi) return lists[lo];
    int mid = (lo + hi) / 2;
    ListNode left  = MergeRange(lists, lo, mid);
    ListNode right = MergeRange(lists, mid + 1, hi);
    return MergeTwo(left, right); // 后序位置合并
}

ListNode MergeTwo(ListNode l1, ListNode l2)
{
    var dummy = new ListNode(); var cur = dummy;
    while (l1 != null && l2 != null)
    {
        if (l1.val <= l2.val) { cur.next = l1; l1 = l1.next; }
        else                  { cur.next = l2; l2 = l2.next; }
        cur = cur.next;
    }
    cur.next = l1 ?? l2;
    return dummy.next;
}
```

#### ⭐ LeetCode 315. 计算右侧小于当前元素的个数（Hard）

**题目：** 给你一个整数数组 `nums`，按要求返回一个新数组 `counts`，`counts[i]` 的值是 `nums[i]` 右侧小于 `nums[i]` 的元素的数量。

**思路（归并排序 + 分治）：** 在归并合并阶段，每当右半部分的元素被放入结果时，说明左半部分中还未处理的元素都比它大，将左半部分当前指针之前的元素的逆序计数加上右半部分已放入元素的个数。用下标数组跟踪原始位置以正确累加计数。

```csharp
int[] counts;
int[] indexes; // 追踪原始下标

public IList<int> CountSmaller(int[] nums)
{
    int n = nums.Length;
    counts  = new int[n];
    indexes = Enumerable.Range(0, n).ToArray();
    MergeSort(nums, 0, n - 1);
    return counts;
}

void MergeSort(int[] nums, int lo, int hi)
{
    if (lo >= hi) return;
    int mid = (lo + hi) / 2;
    MergeSort(nums, lo, mid);
    MergeSort(nums, mid + 1, hi);
    Merge(nums, lo, mid, hi);
}

void Merge(int[] nums, int lo, int mid, int hi)
{
    var tmp = new int[hi - lo + 1];
    int i = lo, j = mid + 1, k = 0;
    while (i <= mid && j <= hi)
    {
        if (nums[indexes[i]] <= nums[indexes[j]])
        {
            // 右边已放入 j-(mid+1) 个，说明 indexes[i] 右侧有这么多更小的
            counts[indexes[i]] += j - (mid + 1);
            tmp[k++] = indexes[i++];
        }
        else tmp[k++] = indexes[j++];
    }
    while (i <= mid)
    {
        counts[indexes[i]] += j - (mid + 1);
        tmp[k++] = indexes[i++];
    }
    while (j <= hi) tmp[k++] = indexes[j++];
    Array.Copy(tmp, 0, indexes, lo, hi - lo + 1);
}
```

## 二十四、字典树 Trie

### 📖 教程讲解

**来源文章**：《Trie 树（字典树）详解》  
🔗 https://labuladong.online/zh/algo/data-structure/trie/

#### Trie 的本质

Trie（前缀树/字典树）是一棵**多叉树**（对于小写英文字母，每个节点最多 26 个子节点），专门用于高效存储和检索字符串集合。

**核心性质：**
- 根节点不存储字符
- 从根到某个节点的路径上的字符，拼接起来就是该节点对应的字符串
- 每个节点用 `isEnd` 标记该节点是否是某个完整字符串的终点

**与哈希表的对比：**

| | Trie | 哈希表 |
|--|------|--------|
| 精确查找 | O(L) | O(L)（计算哈希也需 O(L)） |
| 前缀查找 | O(L) | O(N × L)（遍历所有 key） |
| 有序遍历 | ✅（按字典序） | ❌ |
| 空间 | 较大（节点开销） | 较小 |

Trie 的**核心优势**在于**前缀匹配**，一次 O(L) 的查询就能确定是否存在某个前缀，适合搜索自动补全、拼写检查等场景。

#### 实现要点

- 每个节点含 `children[26]`（或用 `Dictionary<char, TrieNode>`）和 `isEnd` 标志
- **插入**：逐字符走路径，不存在则新建节点，末尾设 `isEnd = true`
- **搜索**：逐字符走路径，路径不通则 `false`，走完后检查 `isEnd`
- **前缀搜索**：逐字符走路径，走完后只要节点不为 null 就是 `true`

---

### 🧩 代码模板（C#）

```csharp
// LeetCode 208. 实现 Trie（前缀树）
public class Trie
{
    private Trie[] children = new Trie[26];
    private bool isEnd = false;

    // 插入字符串
    public void Insert(string word)
    {
        Trie node = this;
        foreach (char c in word)
        {
            int idx = c - 'a';
            node.children[idx] ??= new Trie(); // 不存在则新建
            node = node.children[idx];
        }
        node.isEnd = true; // 标记为完整单词的终点
    }

    // 精确搜索：必须存在且是完整单词
    public bool Search(string word)
    {
        Trie node = SearchPrefix(word);
        return node != null && node.isEnd;
    }

    // 前缀搜索：只要前缀路径存在即可
    public bool StartsWith(string prefix)
        => SearchPrefix(prefix) != null;

    // 辅助：沿路径走到末尾节点，不通则返回 null
    private Trie SearchPrefix(string s)
    {
        Trie node = this;
        foreach (char c in s)
        {
            int idx = c - 'a';
            if (node.children[idx] == null) return null;
            node = node.children[idx];
        }
        return node;
    }
}
```

```csharp
public class WordDictionary
{
    private WordDictionary[] children = new WordDictionary[26];
    private bool isEnd;

    public void AddWord(string word)
    {
        var node = this;
        foreach (char c in word)
        {
            int idx = c - 'a';
            node.children[idx] ??= new WordDictionary();
            node = node.children[idx];
        }
        node.isEnd = true;
    }

    public bool Search(string word) => Dfs(word, 0, this);

    bool Dfs(string word, int i, WordDictionary node)
    {
        if (i == word.Length) return node.isEnd;
        char c = word[i];
        if (c == '.') // 通配符：枚举所有子节点
        {
            foreach (var child in node.children)
                if (child != null && Dfs(word, i + 1, child)) return true;
            return false;
        }
        int idx = c - 'a';
        return node.children[idx] != null && Dfs(word, i + 1, node.children[idx]);
    }
}
```

## 二十五、图的高级算法

### 📖 教程讲解

**来源文章**：《图论算法基础》  
🔗 https://labuladong.online/zh/algo/data-structure/graph-traverse/

#### 图的表示方式

**1. 邻接表：** 用数组或字典存储每个节点的邻居列表，空间 O(V + E)，适合稀疏图（现实中大多数图是稀疏的）。

**2. 邻接矩阵：** 二维数组 `matrix[i][j]` 表示节点 i 到 j 是否有边（或边的权重），空间 O(V²)，适合稠密图，判断边是否存在是 O(1)。

#### 有向图 vs 无向图

- **无向图**：边没有方向（邻接表中双向存储）
- **有向图**：边有方向，可以有环

**图与多叉树的关系：** 树是特殊的图（无环连通图）。图遍历就是多叉树遍历加上 `visited` 数组防止重复访问。

#### 并查集（Union-Find）

并查集用于处理**动态连通性**问题，支持 O(α(N)) ≈ O(1) 的：
- `union(p, q)`：合并两个节点所在的集合
- `find(p)`：找到节点 p 的根（代表元素）
- `connected(p, q)`：判断两节点是否在同一集合

**路径压缩 + 按秩合并** 使操作几乎为 O(1)（反阿克曼函数级别）。

---

### 🧩 代码模板（C#）

```csharp
// 并查集（路径压缩 + 按秩合并）
public class UnionFind
{
    private int[] parent, rank;
    public int Count { get; private set; } // 连通分量数

    public UnionFind(int n)
    {
        parent = Enumerable.Range(0, n).ToArray();
        rank   = new int[n];
        Count  = n;
    }

    public int Find(int x)
    {
        if (parent[x] != x)
            parent[x] = Find(parent[x]); // 路径压缩（递归）
        return parent[x];
    }

    public bool Union(int x, int y)
    {
        int rx = Find(x), ry = Find(y);
        if (rx == ry) return false; // 已在同一集合
        // 按秩合并：小树接到大树下
        if (rank[rx] < rank[ry]) (rx, ry) = (ry, rx);
        parent[ry] = rx;
        if (rank[rx] == rank[ry]) rank[rx]++;
        Count--;
        return true;
    }

    public bool Connected(int x, int y) => Find(x) == Find(y);
}
```

#### ⭐ LeetCode 684. 冗余连接

**题目：** 树可以看成是一个连通且无环的无向图。给定往一棵 `n` 个节点（节点值为 1 到 n）的树中添加一条边后形成的图，找并返回一条可以删去的边，使得删去后图是一棵树。

```csharp
public int[] FindRedundantConnection(int[][] edges)
{
    int n = edges.Length;
    var uf = new UnionFind(n + 1);
    foreach (var e in edges)
        if (!uf.Union(e[0], e[1])) return e; // 合并失败 = 已连通 = 冗余边
    return Array.Empty<int>();
}
```

#### ⭐ LeetCode 200. 岛屿数量（已在第十三章收录，此处补充并查集解法）

**并查集解法：** 遍历网格，遇到 `'1'` 将其与相邻的 `'1'` 合并，最终连通分量数就是岛屿数。

```csharp
public int NumIslands(char[][] grid)
{
    int m = grid.Length, n = grid[0].Length;
    var uf = new UnionFind(m * n);
    int water = 0;
    int[] dx = {0, 1}, dy = {1, 0}; // 只需向右和向下检查（避免重复）
    for (int i = 0; i < m; i++)
        for (int j = 0; j < n; j++)
        {
            if (grid[i][j] == '0') { water++; continue; }
            foreach ((int di, int dj) in dx.Zip(dy))
            {
                int ni = i + di, nj = j + dj;
                if (ni < m && nj < n && grid[ni][nj] == '1')
                    uf.Union(i * n + j, ni * n + nj);
            }
        }
    return uf.Count - water; // 总连通分量 - 水格子数
}
```

## 二十六、数学

### 📖 教程讲解

**来源文章**：《常用数学技巧》

#### 常用数学技巧汇总

**1. 快速幂 — O(log n)**

将指数 `n` 按二进制分解，逐位处理：`x^n = (x^2)^(n/2)`（n 偶数）或 `x × x^(n-1)`（n 奇数）。

**2. 最大公因数（GCD）— 辗转相除法**

`gcd(a, b) = gcd(b, a % b)`，直到 `b = 0` 时返回 `a`。最小公倍数 `lcm = a * b / gcd(a, b)`。

**3. 素数筛 — 埃拉托色尼筛法 O(n log log n)**

从 2 开始，每找到一个素数就将其所有倍数标记为合数（从 `i*i` 开始，因为更小的倍数已被更小的素数筛掉）。

**4. 位运算技巧**

| 操作 | 表达式 | 用途 |
|------|--------|------|
| 判断奇偶 | `n & 1` | 1 为奇，0 为偶 |
| 取最低位 1 | `n & (-n)` | lowbit，树状数组常用 |
| 消除最低位 1 | `n & (n-1)` | 统计二进制中 1 的个数 |
| 判断 2 的幂 | `n > 0 && (n & (n-1)) == 0` | — |
| 异或消除 | `a ^ a = 0`, `a ^ 0 = a` | 找只出现一次的数 |

**5. 同余定理**

`(a + b) % m = ((a % m) + (b % m)) % m`，适用于大数取模场景。

```csharp
// 快速幂：计算 x^n mod p，防止溢出
long QuickPow(long x, long n, long p)
{
    long res = 1;
    x %= p;
    while (n > 0)
    {
        if ((n & 1) == 1) res = res * x % p; // n 为奇数时乘一次
        x = x * x % p;
        n >>= 1;
    }
    return res;
}

int[] GetPrimes(int n)

    var primes = new List<int>();

    {
        if (isComposite[i]) continue;
        primes.Add(i);
        for (long j = (long)i * i; j <= n; j += i)
            isComposite[(int)j] = true;
```

## 二十七、贪心算法

### 📖 教程讲解

**来源文章**：《贪心算法之区间调度问题》  
🔗 https://labuladong.online/zh/algo/essential-technique/greedy/

#### 贪心算法的本质

贪心算法在每个决策点做出**局部最优选择**，期望得到全局最优解。

**贪心与动态规划的区别：**

| | 贪心算法 | 动态规划 |
|--|---------|---------|
| 决策方式 | 局部最优，不回头 | 枚举所有可能，取最优 |
| 是否依赖子问题 | ❌ 只看当前 | ✅ 依赖子问题结果 |
| 适用条件 | 贪心选择性质 + 最优子结构 | 最优子结构 + 重叠子问题 |
| 时间复杂度 | 通常 O(N log N)（排序为主） | 通常更高 |

**贪心选择性质：** 每一步的局部最优选择，不影响后续子问题的最优解，即局部最优能导出全局最优。并非所有问题都满足贪心选择性质，需要证明或反例验证。

#### 区间调度问题（最经典的贪心应用）

**问题：** 从一组区间中选出**最多的互不重叠区间**。

**贪心策略：** 按**结束时间**升序排序，每次选择最早结束且与当前选中区间不重叠的区间。

**为什么按结束时间而不是开始时间？** 选最早结束的区间，给后续留下了最大的「自由空间」，能容纳更多不重叠区间。

**推论：**
- LeetCode 435（无重叠区间）：最少删除数 = 总数 - 最多不重叠数
- LeetCode 452（最少箭射爆气球）：每支箭的射点取当前气球的右边界，之后所有左边界 ≤ 该右边界的气球都能被射爆

---

### 🧩 代码模板（C#）

```csharp
// 区间调度：找最多不重叠区间数
int IntervalSchedule(int[][] intervals)
{
    if (intervals.Length == 0) return 0;
    // 按结束时间升序排序
    Array.Sort(intervals, (a, b) => a[1].CompareTo(b[1]));
    int count = 1, end = intervals[0][1];
    for (int i = 1; i < intervals.Length; i++)
    {
        if (intervals[i][0] >= end) // 不重叠
        {
            count++;
            end = intervals[i][1];
        }
    }
    return count;
}
```

### 📝 习题详解

#### ⭐ LeetCode 435. 无重叠区间

**题目：** 给你一个区间的集合 `intervals`，其中 `intervals[i] = [start, end]`。返回需要移除区间的**最小数量**，使剩余区间互不重叠。

**思路：** 最少删除数 = 总区间数 - 最多不重叠区间数。用区间调度贪心算法计算最多不重叠区间数。

```csharp
public int EraseOverlapIntervals(int[][] intervals)
{
    if (intervals.Length == 0) return 0;
    Array.Sort(intervals, (a, b) => a[1].CompareTo(b[1])); // 按结束时间排序
    int keep = 1, end = intervals[0][1];
    for (int i = 1; i < intervals.Length; i++)
        if (intervals[i][0] >= end) { keep++; end = intervals[i][1]; }
    return intervals.Length - keep; // 总数 - 保留数 = 删除数
}
```

#### ⭐ LeetCode 452. 用最少数量的箭引爆气球

**题目：** 有一些球形气球，用数组 `points` 表示，`points[i] = [xstart, xend]` 表示气球水平跨度。弓箭从某个 x 处垂直射出，能射爆所有满足 `xstart ≤ x ≤ xend` 的气球。求引爆所有气球的**最少弓箭数**。

**思路：** 与区间调度类似，按右端点排序。每支箭射在当前气球的右端点，之后所有左端点 ≤ 该右端点的气球都能被射爆（不需要新箭）。

```csharp
public int FindMinArrowShots(int[][] points)
{
    if (points.Length == 0) return 0;
    // 按右端点排序（注意用 CompareTo 防止溢出，不用减法）
    Array.Sort(points, (a, b) => a[1].CompareTo(b[1]));
    int arrows = 1, end = points[0][1];
    for (int i = 1; i < points.Length; i++)
        if (points[i][0] > end) { arrows++; end = points[i][1]; }
    return arrows;
}
```

#### LeetCode 55. 跳跃游戏

**题目：** 给你一个非负整数数组 `nums`，你最初位于数组的**第一个下标**。数组中的每个元素代表你在该位置可以跳跃的最大长度。判断你是否能够到达最后一个下标。

**思路：** 贪心维护「当前能到达的最远位置」`farthest`。遍历每个可到达的位置，更新 `farthest`。若当前位置超过 `farthest` 说明无法继续。

```csharp
public bool CanJump(int[] nums)
{
    int farthest = 0;
    for (int i = 0; i < nums.Length; i++)
    {
        if (i > farthest) return false; // 当前位置不可达
        farthest = Math.Max(farthest, i + nums[i]);
    }
    return true;
}
```

#### LeetCode 45. 跳跃游戏 II

**题目：** 给定一个长度为 `n` 的整数数组 `nums`，你最初位于数组第一个位置，每个元素代表可以跳跃的最大长度。返回到达最后一个位置的**最少跳跃次数**。

**思路：** 贪心。维护当前步数能到达的最远位置 `curEnd` 和下一步能到达的最远位置 `farthest`。当遍历到 `curEnd` 时必须跳一次，更新 `curEnd = farthest`。

```csharp
public int Jump(int[] nums)
{
    int jumps = 0, curEnd = 0, farthest = 0;
    for (int i = 0; i < nums.Length - 1; i++) // 不遍历最后一个（已到达）
    {
        farthest = Math.Max(farthest, i + nums[i]);
        if (i == curEnd) { jumps++; curEnd = farthest; } // 必须跳一次
    }
    return jumps;
}
```
