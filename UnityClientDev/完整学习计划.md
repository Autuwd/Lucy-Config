## A. 面试TOP15必背清单（每日晨复习用）

```
 1. 生命周期顺序：Awake→OnEnable→Start→FixedUpdate→Update→LateUpdate→OnDisable→OnDestroy
 2. ref vs out：ref双向/必须赋值，out单向/方法内必须赋值
 3. 接口 vs 抽象类：接口是契约/可多实现/无字段，抽象类可有实现/单继承/有字段
 4. 多态实现：virtual/override、abstract、interface
 5. 委托 vs 事件：委托是类型安全函数指针，事件封装委托外部只能+= -=
 6. 协程 vs 线程：协程主线程分步执行/轻量，线程后台并发/不能调UnityAPI
 7. 对象池原理：复用对象减少GC，Get/Return双队列/预加载
 8. TCP三次握手/四次挥手：SYN→SYN+ACK→ACK / FIN→ACK→FIN→ACK
 9. 进程 vs 线程：进程=资源分配单位/独立地址空间，线程=CPU调度单位/共享地址空间
10. 快速排序：分治选pivot，分区递归，平均O(n log n)
11. OSI七层 vs TCP四层：应用-表示-会话-传输-网络-链路-物理 / 应用-传输-网络-网络接口
12. 死锁四条件：互斥/持有等待/不可剥夺/循环等待
13. 虚拟内存：虚拟地址→页表→物理地址映射，缺页中断→页面置换
14. 缓存局部性：时间局部性(重复访问) + 空间局部性(邻近访问)
15. 帧同步 vs 状态同步：帧同步=发输入/确定性/回滚，状态同步=发状态/容错高/RPC

设计模式速记（Day25 九式已完成，09-09 必背）：
  A. 单例(饿汉/懒汉/线程安全) → Unity DontDestroyOnLoad
  B. 观察者 → 事件系统/UnityEvent，一对多解耦
  C. 组件模式 → GameObject+MonoBehaviour挂载，组合替代继承
  D. 状态机 → 角色状态(AI/动画/玩家控制)
  E. 对象池 → Get/Return复用，减少GC峰值
  F. 游戏循环 → 固定步长+可变渲染+插值，Unity FixedUpdate原理
  G. 命令模式 → 撤销/重做、输入缓冲、回放
  H. 工厂模式 → 简单工厂/工厂方法/抽象工厂区别
  I. MVC → Model-View-Controller分层解耦
```
